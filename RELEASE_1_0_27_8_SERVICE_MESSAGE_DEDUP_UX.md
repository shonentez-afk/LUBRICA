# LUBRICA 1.0.27.8 — Service Message Dedup / UX

- Разделены реальные предупреждения, информационные пояснения и технические допущения.
- В простом режиме технические assumptions больше не выводятся как жёлтые предупреждения.
- Для UC/UK/UEL объединены дублирующие сообщения о relube-only policy в одно информационное сообщение.
- Предупреждения о fill ratio и полной замене не показываются для housed_relube_only, потому что эти параметры не участвуют в рабочем цикле.
- LUBM baseline и прочая трассировка перенесены в раскрываемый блок «Технические детали расчёта» только экспертного режима.
- warningCount теперь отражает только реальные предупреждения, а не количество служебных пояснений.
