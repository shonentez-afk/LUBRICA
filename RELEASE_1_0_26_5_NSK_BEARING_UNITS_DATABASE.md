# LUBRICA 1.0.26.5 — NSK Bearing Units Database

Добавлена OEM-база NSK корпусных узлов и вставок UC/UCP 200 (204–212).

- UC204D1…UC212D1: OEM размеры, массы и грузоподъёмность из NSK Online Catalog.
- UCP204D1…UCP212D1: OEM массы узлов; для расчёта первичного заполнения используется масса вставки UC, а не корпуса.
- UCP212 при выборе NSK теперь автоматически связывается с UC212D1, масса 1,46 кг; масса узла UCP212D1 6,7 кг хранится отдельно.
- Для UCF/UCFL/UCT/UCFC 204–212 разрешено использовать подтверждённые OEM-данные вставки UC того же номера; геометрия/масса конкретного корпуса не выдумывается.
- Добавлен источник NSK Ball Bearing Units / NSK Online Catalog.
- Исправлен UX: вместо «NSK · нужен источник» для поддерживаемого корпусного узла показывается «NSK · OEM-источник найден».
- Важно: NSK для стандартных bearing units не задаёт одну универсальную фиксированную дозу пополнения в граммах; LUBRICA не придумывает её. Процедура пополнения остаётся OEM-guidance, а числовая доза должна быть утверждена для конкретной точки/условий.
