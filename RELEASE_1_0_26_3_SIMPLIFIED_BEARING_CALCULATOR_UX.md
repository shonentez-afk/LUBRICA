# LUBRICA 1.0.26.3 — Simplified Bearing Calculator UX

## Цель
Упростить расчёт подшипника для обычного пользователя, сохранив полный инженерный контроль в отдельном экспертном режиме.

## Что изменено
- По умолчанию открывается **Простой режим**.
- Пользователь выбирает производителя и вводит только эксплуатационные параметры; метод досмазывания выбирается автоматически.
- В простом режиме вместо внутренних кодов A/B/C/D/X показываются понятные статусы: точные данные производителя, методика производителя, инженерная оценка, недостаточно данных.
- На экране явно показывается, какой OEM/метод LUBRICA выбрала автоматически.
- **NSK возвращён в видимую логику интерфейса**: для поддерживаемых обозначений показывается «NSK · точные OEM-данные», а в экспертном режиме пункт точной таблицы переименовывается в «NSK — точная OEM-таблица».
- Полный список формул, ручные значения, источники утверждения, базовый интервал, коэффициенты, P/C, скоростная диагностика и полная замена вынесены в **Экспертный режим**.
- В экспертном режиме методики других производителей скрыты по умолчанию. Для межбрендовой оценки требуется отдельно включить «Показать методики других производителей».
- При переключении обратно в простой режим метод автоматически возвращается к `auto_oem`, чтобы исключить случайное сохранение чужой OEM-методики.
- Сохраняется выбранный пользователем режим интерфейса (`uiMode`).

## Логика OEM
- SKF: авто → встроенная SKF-методика.
- NSK: авто → точная локальная OEM-таблица, если обозначение поддерживается; иначе без подмены чужой методикой.
- FAG/Schaeffler: авто сообщает, что требуется выбрать фактический режим в экспертном режиме.
- NTN-SNR: авто → встроенная NTN-SNR методика.
- Timken: без OEM tool/подтверждённых данных автоматическое числовое значение не выдумывается.
