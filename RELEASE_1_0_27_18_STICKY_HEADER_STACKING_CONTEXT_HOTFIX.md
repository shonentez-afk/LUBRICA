# LUBRICA 1.0.27.18 — Sticky Header Stacking Context Hotfix

Исправлена фактическая причина просвечивания/наложения строк на шапку первых sticky-колонок карты смазки.

В 1.0.27.17 непрозрачный фон был задан корректно, но `thead` оставался отдельным stacking context с `z-index:2`. Sticky-ячейки строк имели `z-index:4..6`, поэтому могли отрисовываться поверх всей шапки независимо от `z-index` дочерних `th`.

Изменения:
- `thead` поднят выше всех sticky-ячеек строк (`z-index:60`);
- sticky-заголовки первых трёх колонок подняты ещё выше (`z-index:70`);
- сохранён непрозрачный фон шапки;
- бизнес-логика, данные и ширины колонок не изменялись.
