# LUBRICA 1.0.16 — аудит расчёта полной замены смазки подшипника

## Найденная ошибка

Предыдущая версия показывала `π/4 × (D² − d²) × B` как «геометрический объём» и позволяла получать массу через ручной `Kсв`. Этот объём является только габаритным кольцевым объёмом и не равен свободному внутреннему объёму подшипника. Для UCP212 на d=60, D=110, B=65.1 он равен примерно 434.6 см³, но использовать 434.6 см³ как объём смазки нельзя.

## Исправление

Для обычных подшипников добавлена SKF-оценка свободного объёма через каталожную массу:

`Vсв ≈ π/4 × B × (D² − d²) × 10^-3 − M/(7.8 × 10^-3)`

После этого отдельно задаётся доля заполнения и плотность смазки.

Для `bearing_unit` (UCP/UCF/UCFL/UCT) автоматический расчёт полной замены отключён: расширенное внутреннее кольцо и геометрия корпуса делают универсальную оценку по d/D/B некорректной. Требуется OEM/паспорт/утверждённое инженерное значение.

## UCP212

- d = 60 мм
- D = 110 мм
- B = 65.1 мм
- габаритный кольцевой объём = 434.6 см³ — только справочный показатель, не доза смазки;
- автоматическая полная набивка = заблокирована;
- утверждённое количество вводится только с источником.

Досмазывание для корпусных узлов также получает предупреждение: фиксированная общая формула не должна автоматически считаться утверждённой процедурой для конкретного UCP.
