# LUBRICA 1.0.33.41 — Bearing type series resolution fix

- В карточке подшипника добавлено явное поле «Тип подшипника».
- Тип показывается даже если точного обозначения ещё нет во встроенной библиотеке размеров.
- Серии 222/223/230/231/232/239/240/241 определяются как сферические роликоподшипники.
- Для 23230 добавлена стандартная размерная запись 150×270×96 мм.
- Для точки SNL 530 + 23230 отображается: «Сферический роликовый», а не пустое значение.
- Суффикс фактического исполнения по-прежнему не выдумывается и требует подтверждения по установленному подшипнику.
