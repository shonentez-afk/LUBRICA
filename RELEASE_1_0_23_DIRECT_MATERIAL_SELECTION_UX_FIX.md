# LUBRICA 1.0.23 — Direct material selection UX fix

Исправлен обычный сценарий выбора смазочного материала в мероприятиях.

## Что было

Новые мероприятия создавались в режиме `point_target`. Если у физической точки не был отдельно заполнен TARGET-материал, карточка требовала сначала задать TARGET, хотя в справочнике уже были реальные материалы.

## Что стало

- для новых мероприятий, которым нужен материал, режим по умолчанию — `explicit`;
- пользователь сразу выбирает материал из справочника;
- режим наследования TARGET сохранён только как специальный вариант и недоступен, пока TARGET точки не задан;
- существующее мероприятие с `materialId` всегда открывается как прямой выбор материала;
- старое `point_target` без фактически заданного TARGET автоматически открывается как прямой выбор материала и после сохранения нормализуется;
- инструмент фильтруется по фактически выбранному материалу;
- тексты ошибок больше не требуют сначала задавать TARGET.

TARGET остаётся в инженерной вкладке «Анализ» как утверждённый материал физической точки и не мешает обычному заполнению мероприятий.
