# LUBRICA 1.0.28 — Fan Bearing Arrangement Engine

База: LUBRICA 1.0.27.31 — Fan No Virtual Supports UX.

## Что изменено

- Вентилятор больше не заканчивается тупиковым сообщением при отсутствии импортированных подшипников.
- Для позиции вентилятора запускается отдельный Fan Bearing Arrangement Engine.
- Мастер использует импортированную структуру `позиция V... -> сам вентилятор E... + отдельный электродвигатель`.
- ПЧ и другие электрические ТМЦ не участвуют в модели карты смазок.
- Поддержаны схемы привода: прямой привод, муфта, ремень, другая/неизвестная.
- Для подтверждённого прямого привода на валу двигателя не создаются отдельные подшипники вентилятора.
- Для отдельного вала поддержаны две раздельные опоры и совмещённый подшипниковый блок.
- Убрана архитектурная зависимость `1 корпус = 1 подшипник = 1 точка`.
- Физические маслёнки создаются как точки обслуживания и получают метаданные `fanLubrication` с корпусом, зоной и внутренними подшипниками.
- Для применяемых SNR ZLG зафиксировано 2 маслёнки.
- Для применяемых Tröster 31–33 T L зафиксировано 2 маслёнки.
- DLG не используется.
- SKF SNL поддерживается как семейство корпуса, но количество фактически используемых маслёнок не предполагается автоматически и требует подтверждения.
- Неизвестная маркировка сохраняется без выдумывания внутренней конструкции.
- Добавлен статус готовности: неизвестная схема/подшипники/OEM-методика блокируют расчёт, а не подставляют фиктивные данные.

## Приоритет методики

1. OEM конкретного узла.
2. OEM семейства.
3. OEM фактических внутренних подшипников.
4. LUBRICA Universal 3.2.
5. При недостатке данных — без расчёта.

## Совместимость

Существующая логика 1.0.27.31, запрещающая виртуальные левую/правую опоры, сохранена. Остальные категории оборудования и существующие расчётные модули не изменены.
