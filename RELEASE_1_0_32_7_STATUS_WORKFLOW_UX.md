# LUBRICA 1.0.32.7 — Status & Workflow UX

База: LUBRICA 1.0.32.6. Расчётное ядро, MethodResolver, CalculationPackage, MaintenancePolicy и OEM-методики не изменялись.

## Что изменено

- В карточке точки добавлена единая панель рабочего состояния текущего мероприятия.
- Пользовательские статусы унифицированы: `Готово`, `Требует проверки`, `Требуются данные`.
- В панели явно показана последовательность: `данные сохранены → расчёт применён → мероприятие участвует в плане`.
- Любое редактирование формы помечает карточку как имеющую несохранённые изменения; кнопка меняется на `Сохранить изменения`.
- Статус мероприятия в форме переведён на пользовательскую терминологию без изменения хранимых значений `draft/review/approved/disabled`.
- Добавлена отдельная кнопка `Утвердить мероприятие`; для утверждённого мероприятия она меняется на `Вернуть на проверку`.
- Перед утверждением проверяется наличие периодичности для календарной стратегии и стратегии по наработке. Для `По состоянию` интервал не требуется.
- Утверждённое мероприятие сохраняет существующую семантику `approvalStatus=approved` и участвует в формировании маршрутов. Никакой новой параллельной модели статусов не создано.
- Фильтр и колонка статусов Карты смазки используют те же пользовательские термины.
- Логика единиц периодичности сохранена: по наработке доступны только часы; по календарю — дни/недели/месяцы/годы; по состоянию период не вводится.
