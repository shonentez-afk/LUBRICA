# LUBRICA 1.0.33.24 — Rotating bearing material mode fix

Исправлена семантика материала для подшипниковых мероприятий, созданных Universal Rotating Assembly Constructor.

- `Досмазывание` (`regrease`) и `Полная замена смазки` больше не могут оставаться с `materialMode: none`.
- Старые точки 1.0.33.22/1.0.33.23 автоматически ремонтируются при нормализации базы: если TARGET точки задан — используется `point_target`, иначе `explicit` и пользователь должен выбрать материал из справочника.
- При применении расчета Bearing Engine режим материала также ремонтируется.
- При создании/восстановлении подшипниковых мероприятий seed-задача с `Материал не требуется` больше не переносит ошибочный режим.
- Смазочный материал не назначается вымышленно: если TARGET/явный материал отсутствует, карточка показывает необходимость выбора материала.
