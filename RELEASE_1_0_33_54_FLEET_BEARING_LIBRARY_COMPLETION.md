# LUBRICA 1.0.33.54 — Fleet Bearing Library Completion

## Цель релиза

Закрыть фактические пробелы библиотеки подшипников и корпусных подшипниковых узлов, выявленные полным сопоставлением последней производственной JSON-базы с runtime-библиотекой LUBRICA 1.0.33.53.

## Что добавлено

### 1. Стандартные подшипники — 21 точная запись

Добавлены обозначения из фактического парка: `N216-E-M1-C3`, `23234CCK/W33`, `62305-2RS`, `2211ETN9`, `2213`, `29317E`, `32016X/Q`, `33016Q`, `51112`, `6015-2RS1`, `6016-2RS1`, `21313CC`, `2204E`, `32024X`, `33108-2C`, `51105`, `51106`, `6013`, `6013-2RS1`, `6018-2RS1`, `6024-2RS1`.

Parser сначала выполняет longest exact match по designation/alias, поэтому полные суффиксы `2RS1`, `CCK/W33`, `E.M1.C3` и другие больше не теряются при нормализации.

### 2. Корпусные узлы — 38 записей

Добавлены фактические семейства `CM-UCFC`, `UCFC`, `UCFL`, `UCPA`, `UKF`, `UKFL`, `UKP` и SKF Y-bearing/ConCentra: `SY`, `SYF`, `SYT`, `FY`, `FYTB`, `FYC`, `TU`, `P`.

Для generic UC/UK-позиций производитель полного узла не выдумывается. Геометрия вставки и закрепительная втулка хранятся отдельно от геометрии корпуса. `SYT75F/L` не маскируются под UC/Y-ball: это отдельный `roller_bearing_unit`, для которого универсальная формула количества смазки не применяется.

### 3. Специальные подшипники — 4 записи

Добавлены `YAR206-2F`, `GEH35ES-2RS`, `KR40PP`, `KRE40PP`.

Для `insert_ball`, `spherical_plain`, `track_roller` и `roller_bearing_unit` общий Bearing Calculator не утверждает универсальную дозу/периодичность. Требуется OEM-методика либо подтверждённая локальная процедура.

### 4. Linear Motion — 17 идентификаторов

В отдельный `components/fleet-linear-motion-data.js` добавлены 17 фактических обозначений линейных направляющих/подшипников. Они сопоставляются с существующим модулем Linear Motion и не смешиваются с rolling-bearing calculator. Геометрия, количество смазки и периодичность не предполагаются без документации производителя.

### 5. Безопасная миграция старых BS2-точек

`core/database-normalizer.js` содержит узкий repair для восьми точек старой базы, где фактический импортированный компонент — `BS2-2208-2CS/VT143`, а в точке исторически сохранилось только `2208` с пустыми `d/D/B`.

Repair срабатывает только при наличии точного BS2-контекста. Обычный `2208` без такого источника не изменяется.

## Что намеренно не добавлено в Bearing Library

- Корпуса `SNL`/`SNH` остаются `bearingHousing` context и не становятся rolling bearing.
- 17 Linear Motion позиций хранятся в Component Library / Linear Motion.
- OEM part numbers `3HAA/3HAB/3HAC` не превращаются в стандартные подшипники без подтверждённого соответствия.

## Проверка последней производственной базы

Runtime Bearing Library после расширения: **579 записей**.

На полной последней производственной базе:
- уникальных bearing/linear-bearing наименований: **193**;
- rolling/housed/special: **162 уникальных / 609 фактических вхождений разрешаются библиотекой**;
- Linear Motion: **17 уникальных / 44 вхождения разрешаются отдельной библиотекой**;
- остаток: **14 уникальных / 16 вхождений**, причём все ожидаемые:
  - 11 вхождений — корпуса `SNL/SNH` как housing context;
  - 5 вхождений — OEM part number без подтверждённого bearing designation;
- неожиданных необработанных bearing gaps: **0**.
