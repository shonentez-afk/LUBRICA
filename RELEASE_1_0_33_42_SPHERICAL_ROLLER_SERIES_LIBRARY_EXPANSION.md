# LUBRICA 1.0.33.42 — расширение библиотеки сферических роликоподшипников

- Расширена локальная библиотека серий 223, 230, 231, 232, 239, 240 и 241 до диаметра вала 150 мм; серия 222 уже была покрыта до 150 мм.
- Для каждого базового обозначения сохранены d / D / B и тип `spherical_roller`.
- Суффиксы исполнения E / CC / CA / K / K30 / W33 и т.п. не придумываются: база использует размеры базового ISO-обозначения, а исполнение остаётся фактическим атрибутом ТМЦ.
- Парсер по-прежнему определяет тип по семейству даже для неизвестного размера; теперь для целевого диапазона до 150 мм размеры также находятся автоматически.
- Добавлен регрессионный тест по всем поддержанным семействам и типовым суффиксам.

Целевой диапазон соответствует текущему требованию проекта: роликовые подшипники до d=150 мм.
