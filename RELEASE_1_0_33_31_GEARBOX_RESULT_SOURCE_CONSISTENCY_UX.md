# LUBRICA 1.0.33.31 — Gearbox Result / Source Consistency UX

Исправлены два дефекта расчётного модуля редуктора, выявленные при проверке простого и экспертного режимов.

## 1. Один и тот же результат в простом и экспертном режимах
- Простой и экспертный режимы теперь используют один и тот же текущий результат `Calc.calculate(...)`.
- Если OEM-объём уже определён, простой режим больше не показывает общее «Нужны исходные данные».
- При известном объёме и отсутствующем периоде простой режим показывает, например: `1.1 л · не задан`, а статус объясняет, что требуется только периодичность замены.
- «Рабочий объём не определён» выводится только когда объём действительно отсутствует.

## 2. Источники только через «Обоснование»
- Удалена отдельная кнопка «Источники» из нижней панели редуктора.
- Удалена дополнительная кнопка «Почему такой результат?» из блока результата редуктора.
- Источники, provenance и OEM-доказательства открываются через единую верхнюю вкладку `Обоснование`, как принято в унифицированных расчётных модулях LUBRICA.
- Текст экспертной методики также направляет пользователя в `Обоснование`, а не к отдельной кнопке источников.

## Совместимость
- OEM resolver, таблицы монтажных положений, неоднозначные варианты объёма и синхронизация с мероприятиями не изменены.
- Исправления 1.0.33.25–1.0.33.30 сохранены.
- Версия приложения: 1.0.33.31.
