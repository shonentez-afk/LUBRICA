# LUBRICA 1.0.27.3 — Operating Bearing Maintenance Cycle

- Первичное заполнение удалено из рабочего калькулятора: LUBRICA обслуживает уже смонтированные узлы.
- Два независимых рабочих цикла: досмазывание (г + ч) и полная замена смазки (г + ч).
- Полная замена рассчитывает рабочий запас смазки внутри подшипника после удаления старой смазки; полость корпуса не оценивается без OEM-объёма.
- Период полной замены рассчитывается отдельно: SKF rule ~5 replenishments для бокового пополнения, NTN bearing-unit service-life inference, далее консервативный LUBRICA Universal cycle с поправкой на загрязнение/вибрацию; при tf >= 6 месяцев renewal приравнивается к сервисному интервалу по SKF procedure.
- Быстрое утверждение принимает сразу пару «количество + период» для каждого цикла.
- При сохранении калькулятор создаёт/обновляет оба мероприятия точки: «Досмазывание» и «Полная замена смазки»; каждому передаётся собственное количество и собственная периодичность.
- Legacy aliases старых полей сохранены только для обратной совместимости.
