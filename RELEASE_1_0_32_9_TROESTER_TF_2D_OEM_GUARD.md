# LUBRICA 1.0.32.9 — Tröster tf 2D OEM Guard

## Причина
В 1.0.31.19–1.0.32.8 автоматическое чтение tf Tröster было реализовано через сведение OEM-диаграммы к n*d и постоянные коэффициенты шкал II/III. Официальная инструкция Tröster этого преобразования не публикует: диаграмма является двумерной (скорость n + диаметр отверстия d) с отдельными ординатными шкалами I/II/III.

## Исправление
- Удалена n*d-аппроксимация tf.
- Удалены неподтверждённые коэффициенты шкал II/III.
- Автоматический числовой tf по Tröster заблокирован до появления валидированной 2D-оцифровки.
- Приоритет Ventapp machine-specific interval сохранён без изменений.
- Если Ventapp interval отсутствует, пользователь может применить только подтверждённое чтение tf из OEM-диаграммы Tröster с обязательной фиксацией источника.
- OEM-коррекции Tröster сохранены: ×0,5 для вертикальной установки; ×0,5 за каждый полный шаг +15 °C выше 70 °C; >30 000 ч не рекомендуется.
- Формула дозы Gperiod = 0,005 × D × B не изменялась.

## Источник
Tröster Maschinenbau GmbH, Assembly and Maintenance Instructions for Block Bearings, version 2020-03, Maintenance and Lubrication, diagram page 7.

## Regression
Добавлен `test_release_1_0_32_9_troester_tf_2d_guard.js`: проверяет отсутствие n*d/scaleFactors, блокировку старого auto-tf, обязательность источника ручного tf и приоритет Ventapp.
