# LUBRICA 1.0.26 — Multi-OEM Bearing Calculation Engine

## Цель
Сделать подшипниковый расчёт быстрым, но не скрывать происхождение числа. Приоритет:

1. OEM exact — точная локальная таблица производителя/типоразмера.
2. OEM method — опубликованная методика производителя.
3. Engineering fallback — проверенная инженерная оценка по геометрии/массе.
4. Manual/OEM passport — явное ручное утверждение.

## Производители
- SKF
- NSK
- FAG / Schaeffler
- NTN-SNR
- Timken

## Расширение библиотеки
База дополнена размерными рядами радиально-упорных шарикоподшипников 70/72/73 и самоустанавливающихся шарикоподшипников 12/13. Они помечены как стартовые размерные записи и НЕ считаются OEM-внутренними данными конкретного производителя.

Типы, участвующие в новом движке:
- радиальные шариковые;
- радиально-упорные шариковые;
- самоустанавливающиеся шариковые;
- цилиндрические роликовые;
- сферические роликовые;
- конические роликовые;
- корпусные узлы;
- расширяемые пользовательские типы.

## NSK exact
Локально встроены опубликованные OEM-таблицы дозы/интервала для доступных 6200 series и N/NJ/NU 200 series. При выборе NSK и совпадении обозначения режим «Авто» использует эти числа до универсальной формулы.

Коррекции NSK:
- выше 70 °C интервал уменьшается вдвое на каждые +15 °C;
- P/C: <=0.06 → 1.5; 0.10 → 1; 0.13 → 0.65; 0.16 → 0.45;
- диапазон заполнения свободного пространства зависит от n/Nlim.

## FAG / Schaeffler
Доступны методы дозы:
- еженедельно 0.002 x D x B;
- ежемесячно 0.003 x D x B;
- ежегодно 0.004 x D x B;
- после многолетнего периода 0.01 x D x B.

Оценка свободного объёма по геометрии и массе явно маркируется как Engineering fallback, а не OEM exact.

## NTN-SNR
- стандартная доза G=0.005 x D x B;
- рекомендуемое заполнение 20–30% свободного объёма;
- коррекция базовой частоты Fc=Fb x Te x Ta x Tt реализована для уже имеющихся полей загрязнения, вибрации/вертикального вала и температуры.

## Timken
Добавлен отдельный OEM-профиль. LUBRICA не копирует закрытую внутреннюю формулу Timken: если точной локальной таблицы нет, UI сообщает, что результат требует Timken OEM tool/passport, а не выдаёт приближение за Timken exact.

## Плотность материала
Поле плотности теперь понимает как `0.900 г/см³`, так и `900 кг/м³`: кг/м³ автоматически переводятся в г/см³. Это позволяет использовать данные TDS без ручного пересчёта.

## UI
В расчёте появилась секция «Производитель и методика», показ уровня расчёта и источника, поля `Предельные обороты OEM` и `P/C`, а также кнопка применения доступной OEM-рекомендации заполнения.
