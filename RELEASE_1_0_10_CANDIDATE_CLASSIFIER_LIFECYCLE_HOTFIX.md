# LUBRICA 1.0.10 — Candidate classifier & lifecycle hotfix

## Исправлено 1. «Бабаран натяжной» / «Барабан натяжной»

В исходных данных обнаружена опечатка `Бабаран натяжной`. Старый классификатор искал точное слово `барабан`, поэтому запись оставалась `Не классифицировано`.

Добавлена нормализация распространённой перестановки букв `бабаран` → `барабан`. После обновления классификационной схемы запись автоматически переклассифицируется как:

- тип: Барабан;
- подтип: натяжной;
- статус: Требует проверки;
- схема: две предполагаемые подшипниковые опоры с инженерным подтверждением.

Классификационная версия повышена с 2.0 до 2.1, поэтому существующие неразобранные записи автоматически проходят повторную классификацию при открытии «Кандидатов». Подтверждённые и отклонённые решения не переписываются.

## Исправлено 2. Отклонённые строки оставались в основном списке

Главный фильтр переименован в `Очередь`. Теперь он показывает только записи, с которыми ещё нужно работать.

Из очереди автоматически исключаются:

- подтверждённые;
- отклонённые;
- автоматически исключённые.

История не удаляется. Эти записи доступны через отдельные вкладки `Подтверждено`, `Отклонено` и `Исключено`.

Для уже завершённых решений кнопки повторного подтверждения/отклонения больше не показываются.
