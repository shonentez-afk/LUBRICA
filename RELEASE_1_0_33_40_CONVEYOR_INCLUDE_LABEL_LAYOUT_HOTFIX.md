# LUBRICA 1.0.33.40 — Conveyor include label layout hotfix

Исправлена компоновка строк конструктора конвейеров.

- Переключатель «Включить точку» вынесен в отдельную верхнюю строку карточки.
- Он больше не занимает узкую колонку рядом с «Точка обслуживания» и не может наезжать на соседний текст.
- Поля точки, ТМЦ, категории и положения начинаются со следующей строки.
- Блок мероприятий остаётся отдельной строкой на всю ширину.
- Для узких окон все поля последовательно переходят в одну колонку.
- Логика включения/исключения точки и создание мероприятий не изменены.
