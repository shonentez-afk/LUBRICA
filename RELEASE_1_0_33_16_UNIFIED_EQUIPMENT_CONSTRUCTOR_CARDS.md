# LUBRICA 1.0.33.16 — Unified Equipment Constructor Cards

## Что изменено
- Карточки конкретного вентилятора и ленточного конвейера в разделе «Структура» приведены к единому визуальному шаблону.
- Для обоих типов используется общий блок `structure-arrangement-card`: одинаковая иерархия заголовка, краткого описания, технической сводки и кнопки действия.
- Кнопка конструктора унифицирована: «Открыть конструктор».
- Кнопка конструктора вентилятора убрана из нижнего административного ряда; нижний ряд теперь одинаков для вентилятора и конвейера: «Изменить / Добавить: узел / Удалить».
- В карточке вентилятора сохранены его специфические данные: схема привода, подшипниковая схема, фактический вентилятор, электродвигатель и статус Fan Engine.
- Логика Fan Bearing Arrangement и Conveyor Arrangement не изменялась.

## UX-результат
Пользователь видит одинаковую структуру карточки для оборудования, которое имеет отдельный конструктор: сначала общие паспортные данные, затем блок «Конструкция …» с одной основной кнопкой, затем административные действия.
