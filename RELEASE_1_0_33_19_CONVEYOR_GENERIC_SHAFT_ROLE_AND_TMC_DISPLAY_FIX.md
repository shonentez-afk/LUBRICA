# LUBRICA 1.0.33.19 — Conveyor generic shaft role + TMC display fix

Исправления после проверки двух вариантов ленточного конвейера:

- Для конвейера, где импорт содержит два физических вала, но не указывает словами «приводной» / «натяжной», Conveyor Arrangement всё равно строит каноническую схему 2 вала × 2 опоры = 4 физические подшипниковые точки.
- Если роли валов неясны из импорта, мастер показывает отдельный блок «Распределение валов»: инженер назначает один фактический вал как приводной, второй как натяжной/ведомый. Автоматического угадывания нет.
- Холостой ролик и прочие ролики не попадают в список выбора роли вала.
- После назначения валов отдельно распределяются фактические подшипниковые ТМЦ по четырём опорам.
- Для сервисного UI ТМЦ отображается техническое обозначение без лишнего контекста импорта: удаляются суффиксы «Линия №N» и типовые префиксы «Узел подшипниковый», «Подшипник», «Цепь роликовая».
- Исходное импортированное имя ТМЦ не изменяется: оно сохраняется как canonical/sourceName, а очищенное значение используется только как displayName в сервисном контексте.
- Ручной ввод продолжает использовать тот же Conveyor Arrangement и четыре независимых физических места опор.

Classification version: 2.6.
