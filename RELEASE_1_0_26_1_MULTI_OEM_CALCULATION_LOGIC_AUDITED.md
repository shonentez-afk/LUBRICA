# LUBRICA 1.0.26.1 — Multi-OEM Calculation Logic Audited

Исправления расчётного движка подшипников:
- NSK без точной локальной записи больше не подменяется формулой SKF.
- FAG/Schaeffler Auto больше не выбирает ежемесячный режим самовольно.
- Timken без данных OEM tool не получает чужую автоматическую формулу.
- Добавлены независимые уровни достоверности A/B/C/D/X для дозы, первичного заполнения и периодичности.
- Общий уровень определяется самым слабым звеном, а не одной верхней меткой.
- Источник базового интервала участвует в выборе коррекционной логики.
- Скоростное предупреждение использует n·d_m·bf, а не только n·d_m.
- Нормализация NSK распознаёт распространённые суффиксы (например 6212C3, 6212ZZ).
- Масса из каталога другого OEM помечается как межбрендовая инженерная оценка.
- Первичное заполнение и полная замена разделены. Полная замена не копируется автоматически из первичного заполнения без отдельного OEM/утверждённого источника.

Совместимость: поле calculatedFullFillG сохранено как legacy alias первичного заполнения, но мероприятие `grease_full_replacement` теперь использует только отдельные поля полной замены.
