# LUBRICA Stage 4 — управляемая корректировка паспорта материала

**Статус:** реализация в PR #20 (ветка `feature/stage4-material-passport-guard-20261105`); автоматические тесты и ручная Edge-приёмка — самостоятельные критерии, не считать PR принятым релизом.

## Назначение

Исправлять значения в справочнике смазочных материалов **только по явному решению пользователя**, без автоматического изменения исходного производственного JSON, утверждённых мероприятий, планов, маршрутов и фактов.

Первый фактический кейс: `MAT-0003 / Mobilgear 600 XP 220` с подозрительной плотностью `15,6` г/см³ и конфликтом ISO VG 220 / вязкости 150 мм²/с. Правильное значение следует сверять с действующей редакцией TDS для конкретного продукта. **Тестовые ожидаемые значения в коде не мигрируют производственные данные.**

## Контракт Stage 4

1. Существующий редактор `Материалы` формирует `proposal` без изменения рабочей БД.
2. `LubricaMaterialCorrection.preview` возвращает посимвольный список изменённых полей, связанные task ID, утверждённые мероприятия и предупреждения.
3. Для инженерных параметров требуются причина (не менее 8 символов) и ссылка на паспорт/TDS; для изменения разрешения/статуса — причина.
4. Второе окно подтверждения показывает **ровно тот набор данных**, который сохранится; источник редактируется в первичной карточке, но не после просмотра.
5. Перед `apply` проверяется, что текущая рабочая БД не заменена, запись материала не поменялась и связанные мероприятия не изменили состав/статус.
6. Браузеру запрашивается скачивание полной исходной JSON-копии. Физическое наличие файла в папке «Загрузки» должно подтверждаться в ручной приёмке; программа не заявляет об успешной записи на диск.
7. `apply` выполняется на **отдельном клоне** БД, после чего выполняется `Core.State.setDatabase`.
8. `engineeringCorrectionHistory` сохраняет старые/новые значения, причину, документ и связанные мероприятия.
9. Изменение паспорта **не меняет** `task.approvalStatus`, утверждённую норму/интервал, существующие маршруты или `checklistRuns`; инженер должен перепроверить применимость этих данных.
10. В карточке масло и пластичная смазка различаются по смыслу поля вязкости при 40 °C.
