# Правила работы LUBRICA через GitHub

- `main` — только принятая рабочая база.
- Новые изменения делать в отдельной ветке `work/<краткое-название>`.
- После тестов и acceptance вливать в `main`.
- Каждая принятая версия получает тег `vX.Y.Z`.
- ZIP релиза хранить как release artifact, а не как обычный файл Git-истории.
- Код, тесты, документы, таблицы и небольшие исходные материалы хранить в Git.
- Для каждой версии обновлять `project/PROJECT_STATE_RU.md`, release note и acceptance.
- Новый чат начинать с `START_NEW_CHAT_RU.md`.
