# Release 1.0.33.67 — PP-53736 Gearbox Persistence & Interval Evidence

## Назначение

Версия 1.0.33.67 завершает не только справочник редукторов PP-53736, но и миграцию уже сохранённых производственных данных после 1.0.33.66. Основная цель — не допустить, чтобы исправленный OEM dataset существовал отдельно от старых persisted значений в рабочей JSON-базе.

## Изменения

- Поздний слой `components/gearbox-oem-data-1.0.33.67.js` маркирует новую ревизию standalone R77 и требует инвалидировать старые автоматически применённые quantities при несовместимой OEM-ревизии.
- `components/binding.js` очищает ложное M4, если оно было получено из `DRE100M4`/`DRE80M4`, но не было подтверждено пользователем.
- Для machine profile `IZOTEH-PP53736` persisted generic SEW calendar schedule не имеет приоритета над паспортом машины: рабочий план возвращается к 5000 ч и сохраняет raw `5000/500 h`.
- Значение `500` из `5000/500 h` больше не объявляется «первичной заменой», так как источник не даёт доказанной расшифровки.
- Для подтверждённой конфигурации 8×R77 сборочный лист 53736 4/5 даёт layout hint 4×M1 + 4×M3. Это подсказка/контроль расхождения, а не автоматическая подмена фактической ориентации.
- `gearbox-oil-adapter.js` записывает `mountingPositionSource='user_confirmed'` при явном выборе пользователем и предупреждает о расхождении с machine-OEM hint.

## Реальная БД

Проверено на `Филиал_завода__Техно__г._Юрга(20260923-051134).json`.

- Линия 1 и Линия 2: по 8 R77, S37 = installed.
- S37 на обеих линиях после reconcile связывается с `STD-GBX-SEW-S37`; ложное M4 удаляется.
- В исходной базе Линии 1 найдено 8 старых auto-applied R77 M1 = 3.0 л. Они инвалидируются; текущая OEM величина M1 = 1.2 л остаётся расчётной до повторного явного применения.
- Все PP-53736 gearbox tasks возвращаются к 5000 ч с сохранением `5000/500 h` в source context.
- Повторное применение профиля дважды не изменяет количество equipment/components/points/tasks и не создаёт machine-origin дублей.

## Инженерный контроль R77

Сборочный лист 53736 4/5 содержит четыре R77 в M1 и четыре в M3. В Линии 1 ранее для всех восьми был сохранён M1. 1.0.33.67 сохраняет пользовательский выбор, но R77 №5–№8 помечает как конфликт с drawing hint M3. До подтверждения фактической ориентации окончательное количество масла для этих четырёх приводов не должно утверждаться автоматически.
