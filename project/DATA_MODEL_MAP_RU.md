# LUBRICA — карта модели данных

Документ объясняет смысл ключевых сущностей. Точная структура полей определяется текущей schema в `core/database-schema.js`.

## Основные сущности

### Equipment
Физический объект оборудования в иерархии предприятия.

Может содержать machine-specific context и быть корнем для компонентов и точек.

### Component
Физический или логический узел оборудования: подшипник, редуктор, двигатель, цепной привод и т.п.

Binding связывает фактический компонент со справочной/OEM-записью.

### Lubrication Point
Физическое место обслуживания.

Ключевой принцип: одна точка может иметь несколько мероприятий.

### Task / Event
Конкретное действие обслуживания:
- смазать;
- заменить масло;
- проверить/обслужить;
- другое подтверждённое действие.

Именно task участвует в плане, маршруте, выполнении и строке Excel.

### Material
Смазочный материал или связанный расходный материал.

### Tool
Инструмент/оснастка, назначаемые мероприятию или операции.

### Route
Набор существующих taskId в определённом порядке.

Маршрут не создаёт новые мероприятия.

### Plan / Schedule
Плановое выполнение мероприятий по времени/наработке.

### Checklist result / taskResult
Факт выполнения конкретного task.

### Snapshot / Revision
Зафиксированное историческое состояние маршрута/работы, чтобы поздние изменения не переписывали прошлое.

## Важные связи

```text
Equipment
  └─ Component
      └─ Lubrication Point
          └─ Task(s)
              ├─ Material
              ├─ Calculation result
              ├─ Source/provenance
              ├─ Schedule
              └─ Route membership
```

## Machine profile metadata

Для специализированных конструкторов могут сохраняться:
- origin keys;
- machine profile id/version;
- source/revision markers;
- user-confirmed fields;
- OEM hints;
- migration flags.

## Правило изменения schema

Если новая версия меняет persistent data:
1. обновить schema/normalizer;
2. при необходимости добавить migration;
3. проверить старую production DB;
4. проверить reload/reconcile;
5. добавить regression test.
