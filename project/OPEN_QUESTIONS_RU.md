## A. PP-53736 — подтверждённые открытые вопросы

### 1. R77, Линия 1, позиции №5–№8 — Issue #1 — ЗАКРЫТО КАК ШТАТНЫЙ WORKFLOW

Сборочный чертёж PP-53736 даёт подсказку для второй группы R77: M3. Сохранённое ранее M1 не должно автоматически перезаписываться.

Рабочая логика:
- при создании/настройке карты пользователь выбирает фактическое монтажное положение M1–M6;
- для R77 №5–№8 приложение показывает drawing hint M3;
- если выбранное положение отличается от hint, LUBRICA показывает предупреждение, но не подменяет пользовательский выбор;
- явный выбор сохраняется как `user_confirmed`;
- после выбора LUBRICA автоматически подставляет соответствующий OEM-объём масла;
- до выбора/подтверждения мероприятие может оставаться в `review`, что является корректным состоянием незавершённой конфигурации, а не дефектом программы.

### 2. Запись `5000/500 h` — Issue #2 — ЗАКРЫТО

### 3. Выбор M1–M6 для K37/KF37R17/S37 — Issue #3 — ЗАКРЫТО КАК ШТАТНЫЙ WORKFLOW

M1–M6 не должны заранее угадываться или жёстко прописываться в machine profile.

Рабочая логика:
- при конфигурации редуктора пользователь выбирает фактическое монтажное положение M1–M6;
- LUBRICA по выбранному положению берёт соответствующий OEM-объём из `mountingFillLiters`;
- для KF37R17 объёмы двух масляных полостей показываются отдельно, а сумма используется только для планирования материала;
- смена монтажного положения инвалидирует старый утверждённый объём и требует применить новый расчёт;
- выбранное положение сохраняется с provenance `user_confirmed`;
- токены двигателя `DRE100M4`, `DRE80M4`, `DR63S4` не являются монтажным положением редуктора.

Таким образом, отсутствие заранее выбранного M1–M6 не является дефектом и не блокирует релиз: это обязательный пользовательский шаг конфигурации конкретного установленного редуктора.

## B. Документация

### 4. Актуальность встроенного руководства и скриншотов — Issue #4
В архивной карте встречается указание на скриншоты старой версии интерфейса. После серии 1.0.27–1.0.33 интерфейс и расчётная логика заметно развивались.

Статус: требуется отдельный аудит документации перед следующим крупным production-baseline.

Это не означает, что руководство сейчас неработоспособно; требуется именно сверка его актуальности с текущей версией.
