# LUBRICA — ближайший план развития после 1.0.33.67

## Цель ближайшего этапа

Не добавлять новый большой функциональный блок, пока не закрыта инженерная приёмка текущего PP-53736 и не подтверждено, что вся машина проходит сквозной сценарий без ручных обходов.

## Шаг 1. Закрыть фактические данные PP-53736

- проверить R77 №5–№8 на Линии 1: M1 или M3;
- подтвердить фактические положения K37/KF37R17/S37 там, где они ещё не подтверждены;
- не трактовать `5000/500 h` сверх доказанного источником;
- обновить production DB и provenance после подтверждения.

## Шаг 2. Сквозная machine acceptance

Проверить PP-53736 от структуры до конечного Excel:
- machine profile;
- подшипники;
- цепи;
- винты;
- открытые передачи;
- редукторы;
- материалы;
- мероприятия;
- интервалы;
- план;
- маршруты;
- выполнение/контроль;
- Excel;
- обе линии;
- manual add;
- repeated apply;
- reload/reconcile.

## Шаг 3. Документация

Перед новым production baseline:
- сверить встроенное руководство с текущим UI;
- обновить устаревшие скриншоты;
- проверить developer guide;
- обновить PROJECT_STATE, MODULE_STATUS, ROADMAP и OPEN_QUESTIONS.

## Шаг 4. Следующее расширение

После закрытия PP-53736 выбирать следующий модуль только из реального производственного парка.

Критерий выбора:
1. реальная потребность предприятия;
2. доступная техническая документация;
3. возможность проверить результат на фактической базе;
4. достаточная ценность для программы смазки.

## Версионирование

Следующая версия после принятой 1.0.33.67 получает новый номер только после targeted tests + full regression + acceptance.
