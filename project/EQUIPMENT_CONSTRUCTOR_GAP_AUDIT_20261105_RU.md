# LUBRICA — аудит оборудования и пробелов конструкторов (Stage 5)

Дата: 2026-11-05. Статус: **инженерный аудит; не завершённый релиз**.

## 1. Фактическая база и методика

Источник: пользовательский JSON `Филиал_завода__Техно__г._Юрга(20261105-040121).json`. Анализировался список **всех 1188 записей `equipment`**, их `name`, `lineId`, `equipmentType`; пользовательская JSON не менялась и не коммитится. Сопоставлены рабочие исходники `main`, существующие конструкторы и `project/EQUIPMENT_COVERAGE_MATRIX_RU.md`.

- Линия 1: **629** оборудования; Линия 2: **559**.
- Уникальных строк `name`: **649**.
- `equipmentType`: `other` **812**, `conveyor` **293**, `fan` **28**, `spindle` **32**, `rotating_shaft` **12**, `motor_gearbox` **4**, `pump` **2**, `hydraulic_station` **2**, `crank` **2**, `roller` **1**.
- Проектный производственный baseline: 5659 компонентов, 501 физических точка, 517 мероприятий. Эти значения из принятого предыдущего аудита; **не** считать все кандидаты новыми точками или конструкторными пробелами.
- `equipment` включает и физические агрегаты, и групповые иерархические узлы (например, «Конвейеры», «Шпиндели»), статические конструкции, газоходы, пневматику, площадки, системы без собственной смазки. **812 `other` ≠ 812 отсутствующих конструкторов**.
- Анализ имен/типов оборудования завершён; детальная послойная сверка **каждого** из 5659 `components` с паспортами и созданными точками остаётся отдельной приёмкой. Не приписывать неподтверждённые физические опоры.

## 3. Реальные пробелы и рекомендуемый приоритет

| Приоритет | Машина/семейство из реальной базы | Что уже есть | Пробел / целевое поведение |
|---|---|---|---|
| P0 | Центрифуги волокнообразования; шпиндели (в `equipmentType=spindle` 32 объекта); маслораспылители шпинделей | Universal Rotating | **Centrifuge / Spindle Lubrication Arrangement**: машина → фактические шпиндели → реальные опоры → тип подачи (масляный туман/другая по факту) → обслуживаемые резервуары, фильтры, устройства подачи; не создавать «шприцевание» для масляного тумана |
| P0 | Конвейеры роликовые, ламельные, шнековые | Conveyor 2 shafts / 4 supports, Chain Scraper | **Subtype-aware Conveyor Composition**: использовать текущий движок где схема совпадает; для roller/lamella/screw подтверждать число валов, подшипников, цепей, дозаторов и обслуживаемых полостей отдельно; не переносить 4 опоры по умолчанию |
| P0 | Участок распиловки: пилы продольные, поперечные каретки, гильотины, подшипники и линейные направляющие | Element bearing/linear + Rotating | **Saw / Cut & Traverse Arrangement**: режущий вал/ротор, каретки, линейные опоры, приводы перемещения и дополнительные масляные полости; sealed 2RS без автодосмазывания |
| P1 | Питатели колосниковые и дозирующие (названия встречаются на обеих линиях) | Element chains/gearbox/bearings | **Feeder Arrangement**: привод, фактические валы, механизмы перемещения/вибрации, подшипники, редукторные полости; без предположения о числе опор |
| P1 | Механизмы щёточной очистки, очистка ламелей | Rotating + bearings | **Brush / Cleaning Arrangement**: щёточный вал/привод, физические подшипники, натяжение/перемещение, смазываемые шарниры |
| P1 | Штабеллеры, подъёмники, толкатели и узлы упаковки | Rotating, Oscillating, screw/linear element | **Handling / Stacker Arrangement**: роли подъемной системы, направляющих, приводов, цепей и точек; без автоматического копирования полного механизма между линиями |
| P1 | Измельчитель **LINDNER VEGA 1500** (обе линии) | Element bearing/gearbox/chain | **Shredder Rotor Arrangement** после подтверждения паспорта: роторные опоры, привод, смазочная система, не назначать норму по марке изделия без OEM |
| P2 | Насосные станции, гидростанции | `pump_oem_check`, `oil_system` templates | Превратить шаблон в **Oil System Arrangement** с физическими баками, фильтрами, насосами, измеряемыми/контрольными операциями, источниками, а не фиктивными точками |
| P2 | Мотор-редукторы и мотор-барабаны с фактической комбинацией двигателя/редуктора | motor + gearbox engines/templates | Составной мастер drive-unit и проверка герметичных OEM вариантов, раздельные полости и task approvals |

Отдельного конструктора для каждого газохода, силоса, рамы вентилятора, пневмоцилиндра, площадки или кожуха **не требуется**. Создание точек допускается только на документированном обслуживаемом узле (например, задвижка с редуктором или питатель).

## 4. Архитектурное решение — без множества несвязанных движков

Вводить **расширяемый реестр machine-arrangements**, без замены согласованного интерфейса и без фиксирования OEM как конечного набора. Каждый machine profile содержит:
- `match`: фактический класс + контекст + паспорт и уровень уверенности; название — только hint;
- `composition`: существующие `bearing`, `rotating`, `gearbox_oil`, `chain`, `linear_bearing`, `oil_system`, `oscillating` в роли подузлов;
- `evidence`: `equipmentId/componentId`, source reference, service place, способ подачи, пользовательское подтверждение;
- `preview` и `apply` — по правилам current `LubricaCandidateFinalizer`; ничего не создавать автоматически из пустого шаблона;
- `capabilities` и `unsupported`: если механизм поддержан только частично, показывать «требуется уточнение»;
- `originKey`/idempotence, защита от duplicate, approval, route/fact, повторного импорта и изменения фактической конструкции.

Здесь **нет** предложений переписывать `Fan Arrangement`, `Conveyor Arrangement`, `Rotating Arrangement`, `Oscillating Arrangement` или `PP53736`. Новые семейства должны их переиспользовать.

## 5. План реализации

1. **Stage 5A — read-only gap coverage:** сводка оборудования/семейств по фактическим объектам, разделить `FULL / PARTIAL / REVIEW / CONTEXT / NOT_APPLICABLE`, фильтры по линии/участку и физической очереди; никаких изменений БД.
2. **Stage 5B — семейство конвейеров:** аудит subtypes, запрет silent `TWO_SHAFT_FOUR_SUPPORTS` для неподходящих roller/lamella/screw; фактическое подтверждение.
3. **Stage 5C — центрифуга + шпиндельная подача смазки:** начать с read-only графа физических шпинделей и маслораспылителей, затем транзакционный мастер по источнику.
4. **Stage 5D — распиловка:** механизм режущего вала + система кареток + линейные подшипники + OEM/2RS.
5. **Stage 5E — питатели, очистка, складирование, измельчители, маслосистемы:** включать по результатам кандидатов и документации.
6. После каждой реализации: targeted tests, полный regression, повторный импорт, Line1/Line2, Edge `file://`, backup/recovery, ноль новых виртуальных опор, один `taskId` = одна строка Excel.

## 6. Границы принятия

Аудит списка `equipment` — не подтверждение конструкций всех 5659 компонентов и не автоматическая классификация физической обслуживаемости. До визуального контроля схемы/ТМЦ сохранять review. Перенос по аналогу между Линией 1 и Линией 2 требует отдельного подтверждения фактического соответствия. Исторические approved, факты, маршруты и пользовательские расчёты не переписывать.
