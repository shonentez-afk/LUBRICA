# LUBRICA — постоянные решения проекта

1. Текущая архитектура развивается эволюционно, без переписывания приложения с нуля.
2. Simple/Expert — системный UI-принцип всего приложения.
3. Роли вкладок: Точка / Мероприятие / Анализ / Расчёт.
4. OEM конкретной машины/узла имеет приоритет; fallback не должен скрывать расхождения.
5. Нельзя создавать несуществующие физические опоры и другие виртуальные узлы.
6. Новые OEM, типы оборудования, источники и методики подключаются модульно.
7. Ручное добавление и импорт должны иметь одинаковую функциональность.
8. Повторное применение конструктора должно быть идемпотентным.
9. Для эксплуатируемых подшипников первичное заполнение не является отдельным рабочим результатом.
10. Любое изменение расчётной логики сопровождается целевыми тестами и regression.
11. GitHub после миграции является главным источником актуального кода, проектных решений и handoff для новых чатов.
