# LUBRICA — текущее состояние проекта

## Базовая версия

**1.0.33.67 — PP-53736 Gearbox Persistence & Interval Evidence**.

Эта версия продолжает линию релизов 1.0.5 → 1.0.27+ → 1.0.31+ → 1.0.33.x и включает накопленные исправления расчётной архитектуры, OEM-источников, конструкторов оборудования, импорта, маршрутов, UI/UX и regression QA.

- импорт и классификация производственной структуры;
- точки обслуживания и мероприятия;
- план смазки и маршруты;
- экспорт Excel;
- расчёты подшипников, редукторов, цепей, винтовых подъёмников и электродвигателей;
- OEM/source registry и обоснование расчётов;
- Simple/Expert UX;
- конструкторы оборудования и механизмов;
- полный regression-контур.

## Текущий производственный кейс PP-53736

Источник машины: Izoteh PP-53736, две линии предприятия.

Зафиксировано:
- 102 физические подшипниковые позиции на машину;
- 8 цепных контуров;
- 4 винта подъёмника;
- составной SEW KF37R17 с двумя независимыми масляными полостями;
- поддержка K37, R77, S37 и Tandler A1;
- защита от ложного определения монтажного положения из токенов двигателя M4;
- сохранение machine-OEM контекста;
- проверка Line 1 / Line 2 / manual add / repeated apply / analog copy;
- последняя regression acceptance: PASS.
