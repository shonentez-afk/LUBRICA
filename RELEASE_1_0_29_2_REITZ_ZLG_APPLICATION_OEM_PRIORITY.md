# LUBRICA 1.0.29.2 — REITZ ZLG Application OEM Priority

## Цель
Для вентиляторов REITZ с многоподшипниковыми блоками ZLG применять application-specific таблицу REITZ KXE раньше общей корпусной рекомендации NTN-SNR, сохранив простой интерфейс и полный экспертный контроль.

## Реализовано
- Полностью оцифрована REITZ KXE Table 11 для ZLG: AA/AK — ZLG306–324; AC — ZLG315–324.
- Хранятся внутренние подшипники, пять скоростных диапазонов, доза досмазывания на подшипник/маслёнку и справочное initial/refill значение.
- Для REITZ применяются OEM-интервалы по фактическим оборотам.
- Встроены температурные коэффициенты REITZ для температуры корпуса: 75°C=1.00, 80=0.85, 85=0.70, 90=0.55, 95=0.45, 100=0.35.
- Между табличными температурами LUBRICA использует ближайший более строгий диапазон и явно фиксирует это в инженерных деталях. Выше 100°C автоматический расчёт блокируется.
- Для ZLG316AA при 2980 об/мин и температуре корпуса <=75°C результат REITZ: 96 г на каждую физическую точку досмазывания и 2760 рабочих часов.
- Для ZLG316AC при 2980 об/мин: 18 г на точку и 1600 часов.
- После примерно 10 операций досмазывания выводится указание REITZ удалить накопившуюся старую смазку из корпуса и заменить её.
- Общая NTN-SNR housing method 2024 сохранена как fallback и не удалена.

## Приоритет
REITZ application-specific для вентилятора REITZ > другой OEM конкретного вентилятора/узла > NTN-SNR ZLG housing method > OEM внутренних подшипников > LUBRICA Universal 3.2.

## UX
### Простой режим
Если производитель вентилятора REITZ подтвержден либо методика REITZ была один раз выбрана инженером, пользователь вводит только рабочие обороты и температуру корпуса. Доза, интервал, исполнение AA/AK/AC (если есть в маркировке) и источник выбираются автоматически.

### Экспертный режим
Доступны явный выбор REITZ / другого OEM / NTN-SNR housing method, override исполнения AA/AK/AC, полный источник и раскрываемая полная таблица REITZ.
