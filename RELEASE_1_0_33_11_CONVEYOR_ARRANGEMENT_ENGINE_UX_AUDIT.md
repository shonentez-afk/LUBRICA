# LUBRICA 1.0.33.11 — Conveyor Arrangement Engine + UX Audit

## Цель
Корректно обрабатывать ленточные конвейеры как агрегаты-контейнеры и создавать точки смазки только из фактических импортированных ТМЦ.

## Изменения
- Добавлен шаблон `conveyor_arrangement` для конкретных ленточных конвейеров.
- Группы `Конвейеры` / `Конвейеры ленточные` определяются как структурные контейнеры и не становятся объектами расчёта.
- Из состава конвейера автоматически собираются фактические подшипники, цепи, муфты/втулки, отдельные моторы и редукторы, контекстные валы/барабаны и исключённые пассивные детали.
- Виртуальные левая/правая опоры для конвейеров не создаются.
- Подшипники и цепи включены по умолчанию; неоднозначные муфты/втулки требуют явного подтверждения.
- Электродвигатель и редуктор отображаются как отдельные агрегаты и не превращаются в generic-точки конвейера.
- При подтверждении фактического ТМЦ созданная точка получает `componentBinding`, а исходный компонент переводится в `confirmed`, что исключает повторное создание точки из очереди кандидатов.
- В фильтр кандидатов добавлена категория «Ленточный конвейер».
- Версия классификатора поднята до `2.4`, поэтому существующая база переклассифицируется без ручной очистки данных.

## UI/UX-аудит
После реализации проведён отдельный аудит мастера:
- структура мастера разделена на 4 понятных блока: точки-кандидаты / отдельные агрегаты / контекст / исключённые элементы;
- длинные перечни ограничены внутренней прокруткой, чтобы окно не становилось чрезмерно высоким;
- на узких экранах сетка 4→2→1 колонка;
- вместо двусмысленного «Создать» для конвейера используется «Включить»;
- поле переименовано в «Фактический узел / ТМЦ»;
- перед списком явно объясняется правило отсутствия виртуальных точек;
- двигатель и редуктор визуально отделены от точек смазки.

## Проверка на базе участка камер волокноосаждения
- `10107255 Конвейер ленточный приемный`: 1 подшипник + 1 цепь + 1 мотор-редуктор; валы оставлены контекстом, звёздочки исключены.
- `10207255 Конвейер ленточный приемный №1`: 2 подшипниковых узла + 1 цепь; редуктор и электродвигатель показаны отдельно.
- `10207284 Конвейер ленточный предмаятниковый`: 4 подшипника + муфта + втулка; редуктор и двигатель отдельно; уплотнения исключены.
- `10207302/10207319`: внутренний и наружный маятниковые конвейеры остаются отдельными агрегатами.
