# LUBRICA

Промышленная система управления смазкой оборудования.

## Текущая принятая база

**LUBRICA 1.0.33.68 RC — PP-53736 Full Machine Acceptance & Runtime-Hour Planning**

Главная точка входа для нового разработчика или нового чата:

**[START_NEW_CHAT_RU.md](START_NEW_CHAT_RU.md)**

Единый индекс проектной памяти:

**[project/PROJECT_INDEX_RU.md](project/PROJECT_INDEX_RU.md)**

Перед любыми изменениями сначала пройти индекс проектной памяти. Он ведёт к:
- назначению и направлению проекта;
- текущему состоянию;
- открытым инженерным вопросам;
- дорожной карте;
- постоянным решениям;
- архитектуре;
- политике OEM/источников;
- стратегии тестирования;
- хронике развития;
- истории релизов.

## Назначение

LUBRICA объединяет:
- производственную структуру оборудования;
- точки обслуживания и мероприятия;
- план и маршруты смазки;
- инженерные расчёты подшипников, редукторов, цепей, винтовых подъёмников и электродвигателей;
- OEM/source registry и обоснование расчётов;
- конструкторы оборудования;
- импорт/экспорт и производственную базу;
- Simple/Expert UX;
- regression QA.

## Правило разработки

`main` — только принятая рабочая база. Новые изменения вести в ветках `work/*`, после целевых тестов, полного regression и acceptance вливать в `main`.

Не переписывать проект с нуля и не откатывать ранее принятые инженерные решения.

## Что хранится в GitHub как память проекта

Код и тесты сами по себе недостаточны. Поэтому в `project/` отдельно сохраняются:
- смысл и цели продукта;
- архитектурные правила;
- принятые инженерные решения;
- открытые вопросы;
- дальнейшее направление;
- правила доказательной базы и OEM;
- правила тестирования и приёмки;
- краткая хроника того, как проект пришёл к текущему состоянию.
