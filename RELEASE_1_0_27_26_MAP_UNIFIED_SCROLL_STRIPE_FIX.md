# LUBRICA 1.0.27.26 — Map Unified Scroll / Stripe Fix

Исправлен визуальный шов/полоса в карте смазки, проходивший через колонку «Линия / участок».

Причина: накопившиеся sticky-правила первых колонок создавали отдельные композиционные слои. Даже после снятия sticky с «Линия / участок» граница sticky-слоя «Точка смазки» могла визуально попадать на соседнюю колонку.

Изменение:
- горизонтальный sticky полностью снят со всех колонок карты;
- вся таблица теперь горизонтально прокручивается как единое целое;
- шапка остаётся закреплённой только по вертикали;
- сохранены ширины: «Точка смазки» 210 px, «Линия / участок» 245 px и дополнительный внутренний отступ;
- расчёты, данные и бизнес-логика не изменены.
