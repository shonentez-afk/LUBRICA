# ПРОДОЛЖЕНИЕ ПРОЕКТА LUBRICA — START HERE

Работай с GitHub-репозиторием LUBRICA как с главным источником проекта. Не начинай проект заново.

## 1. Текущая база

Текущая принятая версия: **LUBRICA 1.0.33.67 — PP-53736 Gearbox Persistence & Interval Evidence**.

Перед изменениями прочитай:
- `project/PROJECT_STATE_RU.md`;
- `project/DECISIONS_RU.md`;
- последние `RELEASE_*.md` и `LUBRICA_*_REGRESSION_ACCEPTANCE.txt`;
- релевантные исходные документы из `project/sources/`.

## 2. Основные правила

- не переписывать приложение с нуля;
- не откатывать исправления предыдущих версий;
- сохранять привычную архитектуру и общий UI без необходимости;
- простой и экспертный режим — системный принцип;
- «Точка» = идентификация/место; «Мероприятие» = действие; «Анализ» = материал; «Расчёт» = результат и обоснование;
- изменил точку → сохранил; рассчитал → применил результат; мероприятие участвует в плане только после утверждения;
- не создавать виртуальные физические узлы без подтверждения;
- не придумывать OEM-данные;
- OEM конкретной машины имеет приоритет над общим fallback;
- не выполнять cross-OEM substitution;
- данные OEM, таблицы и методики должны оставаться модульными и расширяемыми;
- ручное добавление должно иметь функциональный паритет с импортом;
- повторное применение конструкторов не должно создавать дубли;
- первичное заполнение подшипника не является рабочим результатом калькулятора; целевые результаты — досмазывание и полная замена.

## 3. PP-53736 — зафиксированная физическая топология

На один PP-53736:
- 102 физические позиции подшипников валков: FY30 = 47, SYF30 = 47, FY40 = 8;
- нижний транспортер: 28 валков × 2 опоры = 56;
- верхний транспортер: 23 валка × 2 опоры = 46;
- 8 физических цепных контуров 12B-2;
- последняя цепь: 5,786 м;
- 4 винта подъёмника ПП1–ПП4;
- 6015-2RS1 не создаёт автоматическую точку периодической досмазки.

Редукторы/приводы машины:
- SEW R77DRE132S4/TF/ES7C/V;
- SEW K37 DRE100 M4/TF;
- SEW KF37 R17 DR63 S4/TF — составной двухсекционный редуктор с двумя масляными полостями;
- SEW S37 DRE80 M4/TF;
- Tandler A1 1:1;III.

`DRE100M4` и `DRE80M4` не означают монтажное положение редуктора M4.

## 4. Проверки перед выдачей релиза

После изменения:
1. выполнить целевые тесты;
2. выполнить полный regression;
3. проверить актуальную производственную JSON-базу, если изменение относится к данным/расчётам;
4. проверить сохранение после reload/reconcile;
5. проверить manual-add parity;
6. проверить отсутствие дублей при повторном применении;
7. обновить acceptance и release note;
8. увеличить номер версии и зафиксировать изменения в GitHub.

Если полный regression упирается в технический timeout, продолжить оставшиеся checkpoints отдельным запуском. Timeout сам по себе не считать функциональной ошибкой, если завершённые тесты PASS.
