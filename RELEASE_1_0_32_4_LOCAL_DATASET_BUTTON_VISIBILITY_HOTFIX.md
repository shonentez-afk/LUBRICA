# LUBRICA 1.0.32.4 — Local Dataset Button Visibility Hotfix

База: `LUBRICA_RELEASE_1_0_32_3_CALCULATION_EVIDENCE_RUNTIME_HOTFIX.zip`.

## Исправлено

В окне «Обоснование расчёта» зарегистрированные offline datasets раньше имели кнопки внизу карточки источника. На высоких карточках они оказывались ниже видимой области, из-за чего создавалось впечатление, что локальные таблицы недоступны.

Теперь для каждого источника, у которого реально зарегистрирован dataset в `LubricaOfflineEvidence`, сразу под заголовком карточки отображается отдельный блок **«Локальные данные»** с кнопкой **«Открыть локальную таблицу»**. Если у источника несколько локальных наборов, показываются отдельные кнопки для каждого набора.

Кнопка создаётся только если dataset существует в offline registry, поэтому пустых/dead actions нет. Внешние OEM-документы остаются отдельными действиями ниже и не смешиваются с локальными таблицами.

Расчётное ядро, MethodResolver, CalculationPackage и OEM-методики не изменялись.
