# LUBRICA 1.0.14 — Project name & KPI tile toggle hotfix

## 1. Имя рабочей базы и корня структуры

Исправлен сценарий, при котором после импорта area4 база и корень структуры отображались как техническое `Завод`, хотя у проекта уже было нормальное полное название в `project.name`.

Теперь:
- если `plants[0].name` пустое или равно `Завод`, а `project.name` содержит осмысленное название, имя завода автоматически восстанавливается из `project.name`;
- если, наоборот, у завода есть осмысленное имя, а `project.name` пустое/техническое, проект получает имя завода;
- новый импорт area4 не создаёт технический `Завод`, если база уже имеет заданное название;
- верхняя панель, Настройки, имя JSON и имя backup используют то же правило выбора имени.

Данные структуры, линии, участки и оборудование не изменяются.

## 2. Повторный клик по верхним плиткам

### Карта смазки
Первый клик по `Готово`, `Требуют проверки` или `Критичные пробелы` применяет статусный фильтр. Повторный клик по уже активной плитке снимает этот фильтр и возвращает `Все`.

### Кандидаты
Первый клик по плитке состояния применяет фильтр. Повторный клик по той же активной плитке возвращает пользователя в `Очередь` — полный рабочий список кандидатов.
