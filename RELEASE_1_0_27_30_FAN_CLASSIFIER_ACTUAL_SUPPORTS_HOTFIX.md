# LUBRICA 1.0.27.30 — Fan Classifier / Actual Supports Hotfix

Исправлена логика классификации вентиляторов и создания подшипниковых точек.

## Что изменено

1. Шаблон `fan_bearings` применяется только к фактическому агрегату вентилятора/дымососа.
2. Рама вентилятора, газоход, воздуховод, кожух и другие вспомогательные элементы больше не классифицируются как вентилятор даже при старом `equipmentType: fan`.
3. Для очевидных вспомогательных элементов старый структурный `equipmentType: fan` при повторной классификации нормализуется в `other`.
4. Для вентилятора сначала ищутся фактические дочерние подшипники/подшипниковые узлы. Если найдены, в мастер создания точек передаются их реальные названия.
5. Если найден только один фактический подшипниковый элемент, он используется как есть; вторая виртуальная опора автоматически не создаётся.
6. Виртуальные левая/правая опоры допускаются только если фактических подшипниковых элементов нет вообще. Они явно помечаются как временные обозначения и по умолчанию не выбраны для создания.
7. Classification version повышена до 2.2.

## Проверки

- фактический `Вентилятор центробежный V22011` остаётся вентилятором;
- `Рама вентилятора`, `Газоход вентилятора`, `Воздуховод вентилятора`, `Кожух вентилятора` не получают `fan_bearings`;
- тест на реальную базу `Филиал завода "Техно" г. Юрга` подтверждает исправление устаревшей классификации рамы и газохода;
- фактические названия подшипников сохраняются в `CandidateFinalizer`;
- виртуальные точки без доказательств не создаются автоматически.
