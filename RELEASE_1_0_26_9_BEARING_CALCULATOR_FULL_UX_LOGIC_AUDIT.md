# LUBRICA 1.0.26.9 — Bearing Calculator Full UX / Logic Audit

Исправления после пользовательского аудита экрана UCP212:

1. Кнопка «Источники» исправлена: в task-editor использовалась несуществующая переменная `global`; теперь используется `window.LubricaBearingSources`.
2. Точное OEM-значение больше не предлагается как доступное для производителя/обозначения, если локальной exact-записи нет.
3. При смене OEM сбрасываются старые метод, базовый интервал и несохранённые утверждения, чтобы данные предыдущего бренда не переносились автоматически.
4. При несовпадении выбранного OEM и каталожной карточки масса другого бренда больше не используется автоматически. Межбрендовая масса разрешается только явным переключателем экспертного режима.
5. В простом режиме добавлена сводка готовности 0–3: доза / первичное заполнение / периодичность. Отсутствие одного блока больше не выглядит как полный отказ калькулятора.
6. Для NTN-SNR исправлена атрибуция методики: дозирование G=0,005×D×B, заполнение 20–30% и схема интервалов привязаны к официальному Lubsolution guide, а Bearing Units Cat. 2400/E оставлен источником продуктовых данных.
7. Первичное заполнение с массой выбранного OEM получает C (OEM mass + engineering free-space), межбрендовая масса — D.
8. Для NSK корпусных узлов в экспертном списке отображается отдельная OEM-процедура, а не фиктивный exact-метод.

## UX-правило

Простой режим показывает только результат и недостающие действия. Экспертный режим позволяет явно выбирать методики, источники и межбрендовые допущения. Скрытые или устаревшие данные другого OEM не должны участвовать в расчёте после смены производителя.
