# LUBRICA 1.0.26.8 — Bearing Calculator Save / Source Hotfix

Дата: 2026-09-08

Исправления:

1. Кнопка «Источники» в открытом модальном калькуляторе больше не пытается открыть второй modal dialog. Реестр выводится как встроенный overlay внутри `bearingCalcDialog`, поэтому работает и в Edge/Chromium при запуске через `file://`.
2. В простом режиме кнопка «Сохранить» сохраняет именно расчёт. Старые скрытые поля `Утверждённое...` без собственного источника больше не блокируют сохранение сообщениями «Укажите источник утверждённой дозы/интервала».
3. Старые утверждённые значения без источника не считаются действующим утверждением. При сохранении в простом режиме они переносятся в `legacyUnverifiedApprovals` для аудита, а активное `approved...` очищается.
4. В экспертном режиме правило не ослаблено: любое введённое пользователем утверждённое значение по-прежнему требует отдельного источника.
5. Простой режим всегда использует OEM-рекомендованную долю первичного заполнения, если она доступна. Скрытое старое значение Kзап (например 1.0) больше не переопределяет автоматическую OEM-рекомендацию.
6. При смене производителя в простом режиме сбрасывается скрытый базовый интервал/бренд источника предыдущего OEM. Это устраняет ситуацию `NTN-SNR` + «база 600 ч, источник NSK».
7. Блок `OEM-данные NSK` теперь скрывается жёстко при выборе другого производителя, даже если стили карточки переопределяют стандартный атрибут `hidden`.
8. Версия расчёта: `multi-oem-1.0.26.8`.
