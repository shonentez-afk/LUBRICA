# LUBRICA 1.0.33.27 — Gearbox Fleet OEM Coverage + Unified UX

## Что изменено

1. Расчётный модуль редуктора приведён к единому UX LUBRICA: простой режим, экспертный режим, обоснование, компактная рекомендация и действие «Применить расчёт».
2. Проведён аудит актуального импортированного парка редукторов и мотор-редукторов.
3. Добавлены недостающие SEW-EURODRIVE семейства S77, FH67, KH77 и FT127 с OEM-таблицами объёма масла по монтажным положениям.
4. Добавлены точные OEM-профили Bonfiglioli для A412/UH45 11.7 P112 B3 (4.3 л), C412/UFB 9.6 P100 B5 (2.4 л), F603 H60 32.1 P132 H1 (14.0 л).
5. Добавлено безопасное распознавание A413, A503, MRV, MW и Brevini SL3003 без выдумывания объёма масла.
6. Для C412/UFB 11.2 P112 B5 найденное значение соседнего исполнения U хранится только как справочное и не применяется автоматически к UFB.
7. В Source Registry / Offline Evidence добавлен Bonfiglioli gearbox fill provenance. OEM-метод выбирается только для записей с подтверждённым fixedFillLiters.
8. Общие строки «Редуктор» без модели намеренно не получают автоматического сопоставления.

## Безопасность инженерных данных

Данные объёма не переносятся между разными OEM, исполнениями или монтажными положениями. Recognition-only запись даёт пользователю найденную модель/семейство, но оставляет рабочий объём на проверку по точной OEM-карточке или шильдику.
