# LUBRICA 1.0.33.53 — UKF211 Housed Bearing Unit Library Hotfix

Добавлена встроенная запись `UKF211` / `UKF 211` для квадратного четырёхболтового фланцевого корпусного узла с втулочным закреплением.

- вал через втулку: 50 мм;
- вставка: UK211;
- закрепительная втулка: H2311 (NSK: H2311X);
- справочный габарит вставки: 100 × 59 мм;
- квадратный фланцевый корпус F211;
- общий размер корпуса: 162 мм;
- межосевое расстояние крепёжных отверстий: 130 мм;
- отверстия: 19 мм, крепёж M16;
- справочная масса полного узла: 3,6 кг по NSK Z-UKF211D1.

Запись является семейной каталожной геометрией и не назначает производителя фактически установленного узла без подтверждения маркировки. OEM-логика NSK при явном выборе NSK использует UK211D1 + H2311X и точную массу корпуса из локальной OEM-строки.
