# LUBRICA 1.0.27.6 — Housed Bearing Relube-Only Policy

## Цель
Безопасно отделить обслуживание стандартных корпусных UC/UK/UEL от будущей логики обычных подшипников.

## Изменения
- Для `bearing_unit` / распознанных UC/UK/UEL введена политика `housed_relube_only`.
- Плановый рабочий цикл: только **досмазывание** (доза + периодичность).
- Полная замена для UC/UK/UEL не рассчитывается и не создаётся автоматически.
- Ранее автоматически созданные калькулятором мероприятия `grease_full_replacement` не удаляются физически: они переводятся в `review`, снимаются с утверждения и помечаются `obsoleteByBearingPolicy`. Это сохраняет историю и исключает их из маршрутного планирования, которое использует только утверждённые мероприятия.
- Ручные мероприятия полной замены не удаляются и не изменяются: инженер может сохранить нестандартный локальный регламент вручную.
- Для обычных обслуживаемых подшипников сохранена прежняя двухцикловая модель. Это важно для следующего этапа расширения на обычные шариковые/роликовые подшипники.
- UI для UC/UK/UEL показывает один рабочий цикл и пояснение о штатном досмазывании с вытеснением; блок полной замены скрывается.
- Версия расчётного движка: `multi-oem-1.0.27.6`.
