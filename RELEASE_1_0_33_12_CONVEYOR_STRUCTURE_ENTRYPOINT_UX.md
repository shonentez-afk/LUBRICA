# LUBRICA 1.0.33.12 — Conveyor Structure Entrypoint UX

- В карточку конкретного ленточного конвейера в разделе «Структура» добавлен явный блок «Конструкция конвейера».
- Блок показывает краткую сводку фактически найденных обслуживаемых ТМЦ и отдельных приводных агрегатов.
- Кнопка «Открыть конструктор» запускает существующий Conveyor Arrangement через Candidate Finalizer для выбранного equipment id.
- Групповые контейнеры «Конвейеры» не получают кнопку конструктора.
- Определение выполняется через общий Component Classifier, поэтому UI не содержит отдельной дублирующей логики распознавания конвейеров.
- Добавлена адаптивная компоновка карточки для узкой правой панели.
