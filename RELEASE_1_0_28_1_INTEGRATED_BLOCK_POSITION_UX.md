# LUBRICA 1.0.28.1 — Integrated Block Position UX

База: LUBRICA 1.0.28 — Fan Bearing Arrangement Engine.

## Изменение

Для схемы `Отдельный вал — совмещённый подшипниковый блок` поле «Положение» удалено из мастера. Оно не является обязательным и не должно заставлять пользователя выбирать «со стороны привода / с противоположной стороны» для единого блока ZLG, Tröster 31–33 T L или другого совмещённого узла.

При сохранении совмещённого блока используется внутреннее значение `NOT_APPLICABLE`; пользовательское поле положения не создаётся, а название фактической точки смазки не получает ложный позиционный суффикс.

Для схемы `Две раздельные опоры` поле положения сохранено без изменений.

## Защитные правила

- ZLG: 2 фактические маслёнки для применяемого семейства.
- Tröster 31–33 T L: 2 фактические маслёнки.
- DLG не используется.
- Неизвестная внутренняя конструкция не выдумывается.
