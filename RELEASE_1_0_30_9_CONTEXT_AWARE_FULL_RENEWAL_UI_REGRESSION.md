# LUBRICA 1.0.30.9 — Context-Aware Full Renewal UI Regression

Исправлен контекст отображения полного обновления смазки.

- ZLG: штатный OEM-сценарий показывает только статус отсутствия планового full-renewal цикла; масса подшипника, плотность и геометрический объём скрыты из рабочего потока.
- VLU: полная замена не имитируется геометрическим калькулятором; остаётся OEM-досмазывание по процедуре.
- Housed units UC/UK/UEL: не запрашиваются пустые поля полного заполнения без отдельной OEM-методики.
- SNL/REITZ: PARTIAL_OEM и FALLBACK_AVAILABLE сохраняют технический блок, потому что там действительно есть OEM-количество и/или осознанный SKF fallback.
- SNL groove: CONDITION_BASED отображается как обслуживание по состоянию/ТО без фиктивной периодичности.
- Standard serviceable bearing: расчёт полного обновления сохраняется, если методика и исходные данные допускают его.
- Инженерные и ручные параметры не выдаются за обязательные поля узлов, для которых плановая полная замена не установлена.

Расчётные формулы и OEM-таблицы не изменялись.
