# LUBRICA 1.0.33.59 — Full Gearbox OEM Dataset Audit

База: 1.0.33.58 Persisted Gearbox Binding Migration Hotfix.

## Что изменено

- Добавлен отдельный OEM dataset `components/gearbox-oem-data-1.0.33.59.js` без ослабления cross-OEM guard.
- Подключены подтверждённые количественные данные фактического парка для Bonfiglioli, SEW-EURODRIVE и Tandler только там, где аудит допускает однозначное значение или набор OEM-вариантов.
- Bonfiglioli A503: таблица A 50 3 по актуальной Rev. 05_5_1; B3 6,1; B6 10; B7 6,2; B8 10; VA 11; VB 7,5 л. Финальный уровень — по OEM level device.
- Bonfiglioli C512/P B6 = 2,9 л; C513/P B3 = 2,9 л; C612/P B3 = 4,1 л; RAN38 B3 = 3,0 л; 301 L2 A = 1,1 л; W/MW/MVF — только подтверждённые конфигурации аудита.
- Исправлен MVF parser: для строк `B5 B6`, `B5 B3`, `B14 B8` монтажным положением считается последний релевантный монтажный B-код.
- A202/A412/A413 и C312/C412/C413 не получают универсальные объёмы по аналогии; точные product-card исключения сохраняются.
- SEW K/S/SA фактического парка получили OEM fills/варианты; неоднозначные R/F значения по числу ступеней сохраняются как варианты, а не выбираются автоматически.
- `KF37R17` остаётся составным агрегатом с обязательным подтверждением — объём K37 на него не переносится.
- ZIMM Z-50-SN блокируется в обычном `gearbox_oil`: сервисный домен `screw_jack_fluid_grease`.
- Lenze GKS04: политика `lifetime_lubricated`; периодический oil_change не назначается автоматически.
- Добавлено распознавание Tandler HW A1; 0,60 л используется как справочный oil-fill только с обязательным подтверждением oil-filled исполнения. STD B1 — 0,80 л с тем же guard.
- UX различает: отсутствует монтажное положение / OEM-объём требует подтверждения / доступны несколько OEM-вариантов.
- Сохранены cross-OEM guard, persisted migration, ручной `actualLibraryEntryId`, material/tool и очистка старых ошибочных OEM quantity.

## Проверка парка

Источник: полный OEM-аудит производственной базы 1.0.33.58 — 186 уникальных обозначений / 335 экземпляров.

- unresolved/guarded: 29;
- manufacturer conflicts, ожидаемо заблокированы: 19;
- wrong-domain, ожидаемо заблокированы: 6;

- расхождений количественных OEM fills: **0**.

## Важное уточнение A 50 3 / VB

В исходных аудитах был конфликт: Rev. 05_4 показывала 12 л, более новая Bonfiglioli Rev. 05_5_1 показывает 7,5 л для A 50 3 / VB. В 1.0.33.59 используется более свежая официальная ревизия — 7,5 л.
