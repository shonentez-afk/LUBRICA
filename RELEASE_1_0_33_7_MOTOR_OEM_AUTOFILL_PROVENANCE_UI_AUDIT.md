# LUBRICA 1.0.33.7 — Motor OEM Auto-fill + Provenance UI Audit

## Исправлено
- Автоматически найденные OEM-каталожные значения двигателя теперь явно отображаются в блоке исходных данных: доза, интервал, источник и confidence.
- Каталожный baseline визуально и структурно отделён от machine-specific override (шильдик/точная инструкция).
- CalculationPackage моторного расчёта получил provenance.catalogBaseline / provenance.machineSpecificOverride без изменения OEM-математики.
- «Обоснование» продолжает открывать только sourceIds текущего расчёта и получает контекст метода/результата.
- Сохранена синхронизация результата с DE/NDE и мероприятиями из 1.0.33.6.

## UI/UX аудит
Проверены длинные названия, перенос источника/confidence, сетка 4→2→1 колонки, отсутствие горизонтального скролла в новых карточках и различимость каталога от шильдика.

## Методика
OEM-таблицы, формулы, MethodResolver и приоритеты не изменялись.
