# LUBRICA 1.0.27.29 — Point Rename / Shared Component Hotfix

Исправлена блокировка редактирования уже существующей точки смазки, когда один элемент структуры является общим механизмом для нескольких физических точек (например, левая и правая подшипниковые опоры вентилятора).

## Что изменено
- При редактировании существующей точки неизменная привязка к тому же элементу структуры больше не считается попыткой создать дубликат.
- Пользователь может переименовать точку, изменить положение на механизме и другие поля без снятия корректной привязки.
- Предупреждение «Элемент уже связан с точкой…» сохраняется при реальной попытке привязать новую/другую точку к уже занятому компоненту.
- В сводке привязки для штатного редактирования показывается нейтральное пояснение о текущей привязке.
- Данные мероприятий, расчётов и идентификатор существующей точки не пересоздаются.

## Контрольный сценарий
Для вентилятора `E 345/71-35.407` существующие точки `Подшипниковая опора левая` и `Подшипниковая опора правая` могут быть поочерёдно открыты через «Изменить привязку» и переименованы в фактические обозначения, не создавая новых точек и не вызывая ложную ошибку дубликата.
