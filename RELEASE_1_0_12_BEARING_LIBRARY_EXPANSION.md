# LUBRICA 1.0.12 — расширение библиотеки подшипников

## Что добавлено

Встроенная библиотека расширена с 55 до 342 записей.

Новые группы:
- цилиндрические роликоподшипники NU2 / NJ2 / NUP2 — до d=150 мм;
- сферические роликоподшипники 222 — до d=150 мм;
- конические роликоподшипники 302 / 322 — до d=150 мм;
- корпусные подшипниковые узлы UCP / UCF / UCFL / UCT — до d=150 мм.

Итого во встроенной базе:
- 55 радиальных шарикоподшипников;
- 66 цилиндрических роликоподшипников;
- 21 сферический роликоподшипник;
- 44 конических роликоподшипника;
- 156 корпусных подшипниковых узлов.

## Корпусные узлы

Для UCP/UCF/UCFL/UCT хранится:
- designation — обозначение узла;
- housingStyle — тип корпуса;
- insertDesignation — вставной подшипник UC;
- d / D / B — размеры вставного подшипника, а не габариты корпуса.

Это сделано намеренно: существующий расчёт количества смазки использует геометрию подшипника. Наружные габариты корпуса не должны подменять D/B подшипника.

## UI библиотеки

Добавлены фильтры:
- по типу подшипника;
- по максимальному диаметру вала: 50 / 100 / 150 мм;
- по источнику.

Поиск теперь понимает:
- обозначение;
- серию;
- тип корпуса;
- вставной UC-подшипник;
- примечания и источник.

## Инженерное ограничение

Встроенная запись является справочной. Перед утверждением нормы, периодичности и способа подачи смазки необходимо проверить фактически установленное исполнение и каталог производителя/OEM.

Для корпусного узла особенно важно проверить путь подачи смазки через корпус и допустимый объём: d/D/B в LUBRICA относятся к вставному подшипнику.
