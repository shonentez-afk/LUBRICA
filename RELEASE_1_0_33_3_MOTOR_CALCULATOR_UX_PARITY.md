# LUBRICA 1.0.33.3 — Motor Calculator UX Parity

## Причина
Моторный калькулятор 1.0.33.1–1.0.33.2 был функционально отдельным, но визуально не соответствовал унифицированному калькулятору LUBRICA. На длинных наименованиях электродвигателей содержимое сжималось и нижние элементы уходили за границы окна. Для Siemens/1TZ дополнительно обнаружена ошибка парсинга строки `N=160кВт n=2982 мин-1`: мощность могла ошибочно трактоваться как обороты.

## Исправления UX
- моторный калькулятор переведён на тот же shell `bearingCalcDialog`, что и основной расчётный модуль;
- добавлены одинаковые верхние режимы `Простой режим / Экспертный режим / Обоснование`;
- шапка, область содержимого и нижняя панель действий разделены; прокручивается только содержимое;
- длинное название двигателя переносится без обрезания;
- окно ограничено размерами viewport и адаптируется к ширине 900/640 px;
- ABB-специфичное поле `Тип подшипника для ABB L1` больше не показывается для Siemens/Innomotics, EMOD, SEW и OLI;
- в простом режиме скрыты технические поля конструкции, но остаются входы, необходимые для текущей OEM-политики;
- в экспертном режиме доступны обороты, мощность, фактическое наличие пресс-маслёнок и ABB L1-контекст.

## Исправления идентификации
`parseRpm()` теперь принимает обороты только при наличии явной единицы скорости (`об/мин`, `мин-1`, `rpm`, `r/min`). Поэтому строка `N=160кВт n=2982 мин-1` разбирается как:
- мощность = 160 кВт;
- обороты = 2982 об/мин;
- серия = 1TZ;
- рама = 315.

Также проверены фактические EMOD WK из структуры:
- `WK 160/2-215T N=37кВт n=9000об/мин` → 37 кВт / 9000 об/мин;
- `WK 160/2-215T правый N=30kW n=6700 об/мин` → 30 кВт / 6700 об/мин.

## Методика
Числовая OEM-логика Siemens/Innomotics и EMOD не расширялась догадками. Для 1TZ/1LE/1LA/1LG и WK по-прежнему действует подтверждённая политика: точные значения дозы/интервала применяются только по табличке смазки или точной OEM-инструкции конкретного исполнения.

## Архитектура
CalculationContext → Motor Method Resolver → Motor Calculator → MaintenancePolicy → Motor UI.
Расчётное ядро подшипников, REITZ/Tröster/Ferrari и существующая ABB-логика не менялись.
