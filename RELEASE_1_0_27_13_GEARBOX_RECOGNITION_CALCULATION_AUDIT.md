# LUBRICA 1.0.27.13 — Gearbox recognition & calculation audit

- Добавлено распознавание цилиндрических SEW R17…R77 внутри полного обозначения мотор-редуктора.
- `R77DV100M4/M2/0` распознаётся как редуктор `R77`, монтажное положение `M2`; двигатель `DV100M4` не смешивается с моделью редуктора.
- Монтажное положение M1…M6 извлекается из структурного обозначения.
- Для OEM-позиций с двумя допустимыми объёмами LUBRICA больше не выбирает один объём молча: показывает оба и требует уточнения исполнения/уровня.
- Для R77/M2 справочник хранит 3.8 / 4.1 л как два OEM-варианта.
- Добавлены OEM-поля обслуживания SEW: контроль масла 3000 ч / не реже 6 мес.; предельный календарный срок замены 36 мес. для минерального и 60 мес. для синтетического масла. В UI по умолчанию подставляется консервативный минеральный срок 36 мес.; тип масла/температура должны быть подтверждены инженером.
- Расчёт редуктора обновлён до 8.5.
