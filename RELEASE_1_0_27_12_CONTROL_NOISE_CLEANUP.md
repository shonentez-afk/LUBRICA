# LUBRICA 1.0.27.12 — Control Noise Cleanup

## Цель
Убрать ложные и многократно повторяющиеся записи со страницы «Контроль», сохранив реальные проверки целостности и инженерные предупреждения.

## Исправлено
- Повторное использование одной записи Справочника (например BRG-UCP212) больше не считается дублированием физической точки.
- Дублирование физической точки проверяется по `candidateOriginKey`; одинаковый физический источник по-прежнему выявляется.
- Отсутствие документального источника материала выводится один раз на используемый материал, а не для каждого мероприятия.
- Если текущих маршрутов ещё нет, выводится одно предупреждение `ROUTES_NOT_CREATED`, а не отдельное предупреждение по каждому утверждённому мероприятию.
- После появления маршрутов сохраняется детальная проверка покрытия каждого утверждённого мероприятия.
- Для предупреждения материала добавлена навигация в раздел «Материалы».

## Проверка на рабочей базе пользователя
До исправления: 144 предупреждения, готовность 84.0%.
После исправления: 12 предупреждений, готовность 98.4%.
Оставшиеся 12 записей являются содержательными для текущей базы:
- 9 × нет источника периодичности для операций «Замена масла»;
- 2 × у используемых материалов нет документального источника/паспорта в карточке;
- 1 × текущие маршруты ещё не созданы.
