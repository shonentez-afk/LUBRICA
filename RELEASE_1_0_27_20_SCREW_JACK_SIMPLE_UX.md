# LUBRICA 1.0.27.20 — Screw Jack Simple UX

## Что изменено
- Калькулятор винтового домкрата FRANCIA упрощён до двух основных пользовательских параметров: **условия среды** и **интенсивность работы**.
- Поля `циклы/ч` и `часы/сут` перенесены в необязательный блок «Дополнительно» и нужны только для показа эквивалента интервала в часах.
- Поле ПВ/duty cycle убрано из простого рабочего сценария; старые расчёты с ним остаются совместимыми.
- Источник утверждения больше не вводится вручную: при принятии рекомендации сохраняется `LUBRICA Engineering · профиль эксплуатации FRANCIA screw jack`.
- Для винта не требуется вводить массу в граммах, если предприятие не проводило калибровку фактического расхода. Рабочая норма — чистый непрерывный слой на рабочей части винта.
- Фактический расход в граммах оставлен только как необязательная калибровка.
- Редукторная часть FRANCIA больше не открывается как обычный масляный редуктор с полями первой/периодической замены масла. Для неё показывается компактный OEM-профиль: объём NLGI 00, контроль состояния и утечек, долив/замена только при необходимости.
- Для M42VR сохраняется OEM-объём 150 см³. Архитектура M35/M55/M75 и будущих винтовых домкратов не меняется.

## UX-принцип
Пользователь должен ответить только на вопрос **«в каких условиях и насколько интенсивно работает домкрат?»**. Остальные инженерные детали скрыты и не мешают рабочему сценарию.
