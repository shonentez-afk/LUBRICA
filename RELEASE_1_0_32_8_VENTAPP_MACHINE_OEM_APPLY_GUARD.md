# LUBRICA 1.0.32.8 — Ventapp Machine OEM Apply Guard

Исправлен UX применения machine-specific данных Ventapp в связке Ventapp fan → Tröster bearing block.

- введённые доза/интервал/смазка Ventapp теперь явно показывают состояние «не применены», пока не указан источник;
- поле источника становится обязательным только при наличии machine-specific данных;
- «Применить расчёт» блокируется, если данные Ventapp введены без источника — молчаливого fallback больше нет;
- после указания источника пересчёт выполняется автоматически, и UI подтверждает, какие именно параметры взяты из Ventapp;
- частичный override сохранён: Ventapp может задать только дозу или только интервал, остальные параметры остаются на Tröster OEM;
- расчётное ядро и приоритет MethodResolver не изменялись.
