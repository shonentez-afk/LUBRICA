# LUBRICA 1.0.19 — Deleted candidate point lifecycle fix

Исправлен жизненный цикл точек, созданных из подтверждённых кандидатов.

- удаление точки из Структуры очищает `candidateCreatedPointIds`/`maintenanceCreatedPointIds`;
- удаление последнего мероприятия из Карты с удалением пустой точки делает то же самое;
- Контроль перед аудитом очищает строго распознаваемые остаточные точки старого бага: candidate-point без мероприятий, всё ещё перечисленная в CreatedPointIds, если у того же подтверждённого кандидата есть другая дочерняя точка с мероприятиями;
- обычные пользовательские пустые точки не удаляются автоматически.

Для пользовательской базы это удаляет устаревший остаток `LP-000017` и не затрагивает `LP-000018`.
