# LUBRICA 1.0.33.32 — Gearbox Interval Resolver Completion

## Исправлено

- Периодичность замены масла больше не остаётся отдельным пустым полем при наличии OEM-политики обслуживания.
- Для SEW-EURODRIVE введён единый семейный maintenance resolver: контроль 3000 ч / 6 мес., предельный интервал замены 36 мес. для минерального и 60 мес. для синтетического масла, если конкретная запись не задаёт более точные данные.
- Значение автоматически пересчитывается вместе с рабочим объёмом и сохраняется в мероприятие `Замена масла`.
- В простом режиме добавлены рабочие поля `Смазочный материал`, `Тип масла` и `Период замены`, поэтому пользователь видит, почему получен интервал и где его изменить.
- Если тип масла можно определить по назначенному материалу, он используется автоматически. Для Mobilgear 600 XP применяется минеральная ветка.
- Если определить основу масла нельзя, LUBRICA не угадывает: пользователь выбирает `Минеральное` / `Синтетическое` прямо в простом режиме.
- Ручное переопределение часов/месяцев остаётся в экспертном режиме; режим `По состоянию / анализу масла` доступен из простого режима.
- Источники и происхождение расчёта остаются только во вкладке `Обоснование`.

## Жизненный цикл

`материал + OEM + монтажное положение -> рабочий объём + OEM-интервал -> Применить расчёт -> мероприятие`

Для SEW `KA57B / M1` при минеральном масле результат становится `1.1 л / 36 мес.` без отдельного ручного ввода периодичности.
