# LUBRICA 1.0.27.11 — Sticky Columns Overlap Hotfix

Исправлено визуальное наложение текста в Карте смазки при открытой боковой карточке точки.

Причина: колонка «Точка смазки» была sticky и имела полупрозрачный фон, а «Линия / участок» при горизонтальной прокрутке проходила под ней. При сужении таблицы боковой панелью это выглядело как пересечение двух надписей.

Изменения:
- первые три колонки (checkbox, «Точка смазки», «Линия / участок») образуют единый sticky-блок;
- заданы точные left-offset по фактическим ширинам колонок;
- sticky-ячейки получили непрозрачный фон;
- состояния hover/active сохраняют единый фон;
- длинные названия точки/участка корректно переносятся внутри своей колонки;
- ширины остальных колонок и логика данных не менялись.

Изменение только UI/CSS, модель данных и расчётные модули не затронуты.
