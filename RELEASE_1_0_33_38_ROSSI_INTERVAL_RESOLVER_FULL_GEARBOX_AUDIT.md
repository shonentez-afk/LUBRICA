# LUBRICA 1.0.33.38 — Rossi Interval Resolver + Gearbox Audit

- Исправлен дефект: для ROSSI MR V 63 при назначенном минеральном масле режим «Автоматически по OEM» больше не оставляет период пустым.
- Для фактически назначенного минерального масла используются интервалы Rossi Operating Instructions: ≤65 °C — 8000 ч; 65–80 °C — 4000 ч; 80–95 °C — 2000 ч. При 95–110 °C автоматический интервал для минерального масла блокируется.
- Для предпочтительного A-series synthetic PAG сохранены интервалы 18000 / 12500 / 9000 / 6300 ч по температурным диапазонам.
- В экспертном режиме вместо двух абстрактных температур теперь четыре OEM-диапазона. Старые `normal/high` мигрируют в ≤65 / 65–80 °C.
- Если для MR V назначено минеральное масло (например Mobilgear 600 XP), интерфейс показывает предупреждение, что A-series OEM предпочитает synthetic PAG ISO VG 320; период можно рассчитать по минеральной таблице, но совместимость материала требует инженерного подтверждения.
- Объём 0.8 л для MR V 63 B3/B8 сохранён.
- Версия runtime/manifest/default DB синхронизирована на 1.0.33.38.
