# LUBRICA 1.0.29.3 — Simple Mode Auto OEM Resolver

## Цель
Убрать обязательный вход в экспертный режим при расчёте ZLG, если пользователю достаточно один раз указать производителя вентилятора.

## Реализовано
- В простом режиме ZLG при неизвестном производителе показывается один компактный выбор: `Производитель вентилятора`.
- При выборе `REITZ` Calculation Resolver немедленно переключается на application-specific `REITZ KXE Table 11`; экспертный режим не требуется.
- Размер/исполнение ZLG берутся из фактической маркировки, обороты и температура — из обычных полей простого режима.
- После сохранения подтверждение REITZ записывается на родительскую позицию вентилятора и автоматически применяется ко второй маслёнке и последующим расчётам этого вентилятора.
- Экспертный режим полностью сохранён: override REITZ / другой application OEM / NTN-SNR housing 2024, ручное исполнение AA/AK/AC, источники и полная OEM-таблица.
- Для неизвестного/другого производителя общий NTN-SNR housing reference не назначается молча как рабочая application-specific норма.
- Убрано требование «сначала зайдите в экспертный режим» из сообщений простого режима.

## UX-принцип
Простой режим спрашивает только фактически недостающий факт. Экспертный режим используется для аудита, проверки источников и переопределения, но не является обязательным шагом штатного расчёта.
