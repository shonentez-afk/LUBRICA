# LUBRICA 1.0.18 — Control orphan point integrity fix

Исправлена UX/интеграция проверки `POINT_WITHOUT_TASKS`.

Контроль не скрывает реальную проблему: физическая точка без мероприятий действительно отсутствует в Карте смазки, потому что Карта строится по мероприятиям. Теперь сообщение объясняет это явно и кнопка открывает такую точку непосредственно в Структуре, где можно добавить мероприятие или удалить пустую точку.

Проверка основана на канонической связи `task.lubricationPointId -> lubricationPoint.id`.
