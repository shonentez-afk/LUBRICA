# LUBRICA 1.0.33.15 — Conveyor Bearing Support Assignment

## Исправлено

Конструктор ленточного конвейера больше не назначает первый найденный подшипниковый узел всем четырём опорам, если импорт содержит несколько разных узлов и их положение не определено.

Для подтверждённой двухвальной схемы явно используются четыре физических места:
- приводной вал — левая опора;
- приводной вал — правая опора;
- натяжной/ведомый вал — левая опора;
- натяжной/ведомый вал — правая опора.

Если импорт содержит несколько подшипниковых узлов (например UCPA 210 и UKHA 212), инженер обязан назначить конкретный импортированный узел каждой опоре. До заполнения всех четырёх мест подтверждение блокируется. LUBRICA не угадывает принадлежность узла к валу.

Если найден только один тип/узел, он предлагается как исходное значение для четырёх позиций, но остаётся явным назначением в конструкторе.

## Ручной ввод

Для вручную создаваемого конвейера форма оборудования содержит четыре независимых поля подшипниковых опор. Эти значения создаются как четыре фактических компонента и автоматически привязываются к соответствующим позициям Conveyor Arrangement Engine.

Старое одиночное поле `Подшипник / тип опоры` оставлено только как миграционный fallback внутри данных и больше не используется в новом UI.
