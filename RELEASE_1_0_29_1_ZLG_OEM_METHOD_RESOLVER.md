# LUBRICA 1.0.29.1 — ZLG OEM Method Resolver

## Цель
Устранить автоматическое применение обычной формулы внутреннего подшипника к точкам SNR ZLG и не перегружать пользователя выбором методик.

## Реализовано
- Добавлен OEM housing reference NTN-SNR ZLG (DOC_I_ZLG_OM1_A4_GBa-26072024B).
- Для ZLG316 хранится 227 см3 на подшипниковую позицию и базовый интервал 3000 ч, минимум 2 раза/год. Масса выводится только через явную плотность (reference 0.9 г/см3).
- Housing-level reference НЕ назначается автоматически на высокооборотном вентиляторе. По умолчанию действует guarded_auto: расчёт блокируется до подтверждения области OEM-методики.
- Экспертный режим позволяет выбрать: application-specific OEM конкретного вентилятора/узла; NTN-SNR ZLG housing instruction 2024; либо оставить guarded_auto.
- Простой режим не показывает формулы и лишние поля. После однократного инженерного выбора сохранённая методика применяется без дополнительных вопросов.
- Для ZLG отключено автоматическое смешивание housing-level интервала с коэффициентами LUBRICA/NTN generic.
- Первичное заполнение ZLG не превращается в рабочий цикл полной замены.

## Приоритет
OEM конкретного вентилятора/узла > OEM корпуса/семейства ZLG > данные внутренних подшипников > LUBRICA Universal 3.2 > блокировка при недостатке данных.
