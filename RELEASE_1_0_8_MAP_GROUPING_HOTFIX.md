# LUBRICA 1.0.8 — Lubrication map point grouping hotfix

## Исправлено

В Карте смазки одна физическая точка с несколькими мероприятиями раньше визуально отображалась как несколько одинаковых точек, потому что каждая строка мероприятия полностью повторяла Point ID, местоположение, категорию и оборудование.

## Новое отображение

Теперь Карта группирует строки по физической точке:

- Point ID и название точки показываются один раз;
- линия/участок показываются один раз;
- категория показывается один раз;
- оборудование/узел показываются один раз;
- мероприятия остаются отдельными строками внутри этого визуального блока;
- у точки показывается количество мероприятий.

Пример:

LP-000001 — Подшипниковая опора левая — 2 мероприятия
  • Досмазывание
  • Полная замена смазки

LP-000002 — Подшипниковая опора правая — 2 мероприятия
  • Досмазывание
  • Полная замена смазки

## Важно

Данные не объединяются и не удаляются.

Архитектурный инвариант сохраняется:

**одна строка данных = одно мероприятие**

Поэтому taskId, маршруты, планирование, выполнение, Контроль и Финальный Excel продолжают работать по отдельным мероприятиям.

Изменено только визуальное представление Карты смазки.
