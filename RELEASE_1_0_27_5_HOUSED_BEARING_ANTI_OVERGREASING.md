# LUBRICA 1.0.27.5 — Housed Bearing Anti-Overgreasing

## Цель
Исключить применение общей формулы 0,005×D×B как основной рекомендации для UC/UK/UEL и корпусных узлов, когда доступна специализированная OEM-таблица количества досмазывания для этой конструкции.

## Изменения
- Universal 3.1 использует NTN/NTN-SNR UC/UK/UEL relubrication table как конструктивно-специализированный reference для housed units.
- При выбранном NTN/NTN-SNR таблица остаётся OEM exact (A); при другом бренде она используется только как явно маркированный межбрендовый инженерный ориентир (D), а не как OEM другого производителя.
- Для UCP216/UC216 reference = 15,5 г при ρ=0,9; для UCP320/UC320 reference = 60 г при ρ=0,9.
- Плотность отличная от 0,9 пересчитывает массу пропорционально объёму.
- Экспертные методы, выдающие более 125% специализированного housed-unit reference, получают `overgreaseRisk` и блокируются от быстрого автоматического утверждения.
- Все старые утверждённые расчёты автоматически помечаются требующими пересчёта из-за новой версии `multi-oem-1.0.27.5`.
