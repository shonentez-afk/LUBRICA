# LUBRICA 1.0.33.35 — Conveyor Candidate Cleanup & Optional Selection UX

- Закрепительные/переходные втулки подшипников вида H3xx исключаются из самостоятельных точек смазки.
- Конструктор ленточного конвейера показывает канонические 4 физические подшипниковые опоры даже если в импорте нет двух явно названных валов; подшипники не придумываются и назначаются инженером из фактических ТМЦ.
- Муфты, втулки и прочие дополнительные ТМЦ не включаются автоматически; цепь и отдельный редуктор остаются рабочими предложениями.
- Для каждой строки конструктора добавлен заметный переключатель «Включить точку». Отключённая строка визуально гасится и не создаёт точку/мероприятия.
- Это позволяет удалить лишнее непосредственно в мастере без правки исходного импорта.
