# LUBRICA 1.0.27.10 — Status Semantics & Table Width UX

## Что исправлено
- В таблице карты смазки колонка `Статус` переименована в `Статус мероприятия`, чтобы не путать её со статусом физической точки.
- В карточке добавлены пояснения к статусу точки и статусу мероприятия.
- Зафиксированы минимальные ширины колонок карты смазки. `Точка смазки` и `Линия / участок` больше не должны визуально наезжать друг на друга; при недостатке ширины используется горизонтальная прокрутка таблицы вместо сжатия текста.

## Семантика текущей версии
- `Статус точки` хранится у `lubricationPoint` и описывает жизненный цикл физической точки: кандидат / на проверке / подтверждена / не обслуживается / выведена.
- `Статус мероприятия` хранится у `task.approvalStatus` и является операционным. Автоматическое формирование маршрутов использует только мероприятия со статусом `approved`/`ready`.
- Колонка статуса в основной таблице показывает именно статус мероприятия.

## Важно
В 1.0.27.10 не менялась маршрутная бизнес-логика статуса точки, чтобы не исключить существующие утверждённые мероприятия из маршрутов без явной миграции данных. Это отдельное решение уровня бизнес-правил.
