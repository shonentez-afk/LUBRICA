LUBRICA Bearing Library — Release 1.0.12

Назначение:
- локальный поиск подшипника и корпусного узла;
- распознавание обозначения и суффиксов;
- использование подтверждённых d / D / B в инженерных расчётах;
- пользовательские подтверждённые записи bearingOverrides в JSON.

Встроенная библиотека:
- радиальные шарикоподшипники 6000 / 6200 / 6300;
- цилиндрические роликоподшипники NU2 / NJ2 / NUP2;
- сферические роликоподшипники 222;
- конические роликоподшипники 302 / 322;
- корпусные подшипниковые узлы UCP / UCF / UCFL / UCT;
- максимальный диаметр вала встроенного расширенного набора: 150 мм.

Корпусные узлы:
- поля d / D / B описывают вставной подшипник UC, а не наружные габариты корпуса;
- дополнительно хранятся housingStyle и insertDesignation;
- расчёт по d / D / B не является подтверждением допустимого объёма смазки корпуса; схему подачи и интервал сверять с OEM.

Все встроенные записи являются локальной инженерной справочной базой. Перед утверждением нормы или периодичности необходимо подтвердить конкретное исполнение по каталогу производителя/OEM.
