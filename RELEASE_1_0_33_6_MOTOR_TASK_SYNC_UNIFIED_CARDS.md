# LUBRICA 1.0.33.6 — Motor Task Sync + Unified Cards

## Исправлено

1. Результат моторного расчёта теперь применяется ко всем фактическим точкам DE/NDE одного электродвигателя, а не только к открытой точке.
2. В мероприятии синхронизируются не только approved-значения, но и calculated dose/interval и их источник. Это устраняет ситуацию, когда карточка одновременно хранила старый Universal Bearing result и новый Motor OEM result.
3. Если расчёт уже сохранён на одной опоре двигателя, вторая опора использует тот же сохранённый motorService-контекст при открытии.
4. Старое мероприятие, отключённое моторной политикой, может быть корректно восстановлено при переходе к RELUBE-политике.
5. Моторный калькулятор приведён к той же визуальной иерархии, что остальные калькуляторы LUBRICA: рекомендация → краткие карточки → исходные данные → экспертная корректировка → machine-specific override → результат.
6. Серийные OEM-значения (например Lammers 1TZ9 30 г / 3000 ч) больше не выглядят как пустые поля «таблички». Они показываются в автоматическом OEM-блоке; поля таблички остаются отдельным machine-specific override и не подменяют источник.

## Без изменения методики

Расчётные таблицы и OEM-формулы не изменялись. Изменены только lifecycle результата, синхронизация мероприятия и UI Presenter моторного модуля.
