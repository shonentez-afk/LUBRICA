# LUBRICA 1.0.27.24 — Location Column Scroll UX Hotfix

Исправлено поведение карты смазки при горизонтальной прокрутке.

- Горизонтально закреплены только чекбокс и колонка «Точка смазки».
- Колонка «Линия / участок» больше не является отдельной sticky-колонкой и прокручивается вместе с таблицей.
- Непрозрачный фон закреплённых колонок сохранён, поэтому текст прокручиваемых колонок не просвечивает под ними.
- Ширины колонок и бизнес-логика не изменялись.
- Поведение шапки при вертикальной прокрутке сохранено.
