# LUBRICA 1.0.17 — SKF masses and quick bearing calculation

В библиотеку добавлены и/или уточнены SKF корпусные подшипниковые узлы, которые фактически встречаются в пользовательской базе: UCP 212, UCP 216, UCT 210, UCFC 208, UCFC 211, UCP 320.

Для каждой записи хранятся раздельно:
- `insertMassKg` — масса вставного подшипника UC;
- `unitMassKg` — масса узла целиком;
- `manufacturer = SKF`;
- источник данных.

Важно: в расчёте свободного объёма используется только масса вставного подшипника, а не масса корпуса.

## Быстрый расчёт

Если выбран SKF корпусной узел, окно расчёта автоматически подставляет массу вставного подшипника из каталога. Для полной замены/первичной набивки предлагается `Kзап = 1,00`; это соответствует полной набивке самого подшипника по SKF. Масса узла показывается только справочно.

Плотность берётся из выбранного смазочного материала, если она заполнена в библиотеке материалов. Если плотности нет, пользователь вводит её один раз по TDS/SDS.

Кнопка **«Принять расчёт»** переносит рассчитанное количество в утверждённое поле и автоматически формирует источник расчёта.

Для UCP212 при d=60, D=110, B=65,1 мм, массе вставки UC212 1,50 кг и плотности 0,90 г/см³ расчёт даёт около 218,06 г при Kзап=1,00.

Масса корпуса/узла никогда не подставляется вместо массы подшипника. Это защищено тестом.
