# LUBRICA 1.0.33.63 — Izoteh PP-53736 Lubrication Constructor

## Основание

Реализация выполнена по пользовательскому паспорту Izoteh `PP-53736-YU1`, сборочный чертёж `53736`, 2014 г., и по актуальной рабочей базе `Филиал_завода__Техно__г._Юрга(20260923-023529).json`.

## Реализовано

1. Корневой объект `Гофрировщик-подпрессовщик` распознаётся как машинный OEM-профиль и получает отдельный конструктор в панели структуры и очереди кандидатов.
2. Профиль не заменяет существующие калькуляторы: редукторы идут в `gearbox-oil`, цепи — в `chain`, подшипники — в `bearing`, винты подъёмника — в `screw`, зубчатая рейка/колесо — в `open-gear`.
3. Из OEM-сборочной спецификации фиксируются восемь цепей 12-B2 с длинами 3.812, 3.549, 3.737, 3.747, 4.093, 4.143, 4.375 и 5.768 м. Для них создаются восемь физических цепных контуров с интервалом 200 ч.
4. По паспорту создаются четыре физические позиции винтов подъёмника с интервалом 800 ч.
5. Фактические подшипниковые ТМЦ получают отдельные точки с машинным интервалом 200 ч. Закрытый `6015-2RS1` исключён из автоматического планового досмазывания.
6. Фактические K37, KF37R17 и Tandler A1/HW A1 включаются в существующий расчёт редукторов. Машинная OEM-запись `5000/500 h` сохраняется в расписании как исходное значение; рабочий интервал выставляется 5000 ч.
7. Количество приводов R77 не выбирается автоматически: текст руководства и сборочная спецификация расходятся. Инженер задаёт фактическое количество 1–8.
8. S37 DRE80 M4/TF показан как отдельный вопрос. При выборе «Установлен» компонент создаётся из паспорта; при «Не установлен» точка не создаётся; по умолчанию остаётся «Требует уточнения».
9. Для Линии 2 конструктор восстанавливает отсутствующий корневой объект `10208190`, перепривязывает уже существующие группы `10208201`, `10208214`, `10208232`, а также компоненты с `parentEquipmentExternalCode=10208190`.
10. Конфигурацию можно применить к аналогу на второй линии без копирования чужих component-id: используются фактические компоненты соответствующей линии.

## Источники

В релиз встроены локальные OEM-документы:

- `assets/oem/izoteh/53736_Predpresa_RUS.pdf`;
- `assets/oem/izoteh/53736_predpresa_1.pdf` … `53736_predpresa_5.pdf`.

В реестр источников добавлены `IZOTEH-PP53736-MANUAL` и `IZOTEH-PP53736-DRAWING`.

## Защитные правила

- виртуальные подшипники не создаются;
- закрытый 6015-2RS1 не получает ложное досмазывание;
- R77 и S37 не создаются автоматически без подтверждения;
- существующие компоненты Линии 2 перепривязываются, а не дублируются;
- повторное сохранение конфигурации идемпотентно: точки и мероприятия не размножаются.
