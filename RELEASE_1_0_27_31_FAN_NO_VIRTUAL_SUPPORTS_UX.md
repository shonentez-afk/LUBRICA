# LUBRICA 1.0.27.31 — Fan No Virtual Supports UX

Исправлен оставшийся UX-regression после 1.0.27.30.

Если для фактического вентилятора в импортированной структуре не найдены реальные подшипники/опоры, мастер инженерного подтверждения больше не показывает условные строки «Подшипниковая опора левая/правая» даже как невыбранные временные варианты.

Теперь мастер показывает информационное сообщение и не позволяет создать фиктивные опоры. Пользователь должен сначала подтвердить/добавить реальные подшипниковые элементы в структуре либо создать фактическую точку вручную в Карте смазки.

Если найден один или несколько реальных подшипниковых элементов, используются только их фактические названия.
