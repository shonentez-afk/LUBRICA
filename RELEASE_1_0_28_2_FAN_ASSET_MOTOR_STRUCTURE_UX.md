# LUBRICA 1.0.28.2 — Fan Asset + Motor Structure UX

База: LUBRICA 1.0.28.1 — Integrated Block Position UX.

## Исправлено

- В структуре позиции вентилятора теперь явно показываются два импортированных физических объекта, значимых для карты смазок: **сам вентилятор** и **электродвигатель**.
- Преобразователь частоты и прочие электрические ТМЦ в ветку карты смазок не выводятся.
- Подтвержденные Fan Bearing Arrangement узлы и точки отображаются внутри ветки физического вентилятора.
- Импортированная `Рама вентилятора` также отображается внутри ветки физического вентилятора и больше не выглядит родителем совмещенного подшипникового блока.
- Узлы и точки, созданные из кандидата электродвигателя, отображаются внутри ветки электродвигателя.
- В карточке физического электродвигателя добавлена команда `Подшипники электродвигателя`; она запускает существующий инженерный мастер кандидата двигателя.
- В интерфейсе Fan Engine убрано отдельное упоминание ПЧ.

## Архитектурное правило

```text
Позиция V...
├─ Сам вентилятор E ...
│  ├─ импортированные механические элементы вентилятора
│  └─ фактическая подшипниковая схема Fan Engine
└─ Электродвигатель ...
   └─ собственные подтвержденные подшипники / точки смазки
```

Исходные импортированные компоненты не преобразуются и не дублируются в `equipment`: дерево показывает их как физические активы внутри позиции, сохраняя исходную модель данных.
