# LUBRICA 1.0.26.7 — NSK Housed Unit UI / Source Hotfix

## Исправлено

1. Кнопка «Источники» в подшипниковом калькуляторе больше не пытается открыть реестр внутри уже используемого `actionDialog`. Реестр создаёт отдельный `bearingSourceRegistryDialog`, поэтому калькулятор остаётся открытым, а источник можно просматривать поверх него и затем вернуться к расчёту.
2. Для NSK-корпусного узла с найденным OEM-профилем скрывается исходная справочная карточка другого OEM. Вместо неё показывается только блок «OEM-данные NSK» с обозначением вставки, размерами, массой и OEM-источником.
3. Состояние досмазывания NSK без опубликованной фиксированной универсальной дозы больше не выглядит как сломанный расчёт: вместо пустого тире выводится «По процедуре NSK» с пояснением. Число не выдумывается и не подменяется формулой другого OEM.
4. В простом режиме при наличии OEM-рекомендации доли первоначального заполнения и пустом Kзап LUBRICA автоматически применяет рекомендуемое значение и пересчитывает первичное заполнение. Для NSK это требует доступной рекомендации по скорости (rpm и limiting rpm); при отсутствии необходимых исходных данных значение не выдумывается.
5. Версия расчёта повышена до `multi-oem-1.0.26.7`.

## Инженерное правило

Для NSK UC/UK housed units наличие OEM-каталога и OEM-процедуры не означает наличие универсального значения граммов на одно досмазывание. Если конкретная OEM-доза отсутствует, LUBRICA хранит это как OEM guidance (B), а числовое утверждённое значение требует отдельного регламента/источника либо явно выбранной инженерной оценки.
