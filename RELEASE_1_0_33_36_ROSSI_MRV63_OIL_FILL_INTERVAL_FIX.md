# LUBRICA 1.0.33.36 — Rossi MR V 63 oil fill + interval fix

- Исправлена ошибочная атрибуция `MRV 63 UO3A` к Bonfiglioli: семейство относится к Rossi A series.
- Для `MR V 63 UO3A / 16` добавлен локальный OEM-профиль: ориентировочный рабочий объём 0.8 л для стандартной B3/B8-конфигурации, синтетическое масло ISO VG 320.
- Добавлен OEM-период для синтетического масла Rossi: 18000 ч при T масла <=65 C; 12500 ч при 65-80 C. Более высокие температуры остаются экспертным уточнением по OEM-таблице.
- Gearbox Engine теперь использует Rossi как самостоятельное OEM-семейство и не смешивает его с Bonfiglioli.
- При наличии `technicalData.mountingPosition` положение автоматически подставляется в рабочий расчёт.
- После `Применить расчёт` количество и период синхронизируются с мероприятием `Замена масла` существующим механизмом 1.0.33.33.
