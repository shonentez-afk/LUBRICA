# LUBRICA 1.0.33.57 — Gearbox Fleet Completion & Cross-OEM Guard

Версия продолжает 1.0.33.56 и закрывает выявленные пробелы справочника редукторов на фактической производственной базе.

## Что добавлено

- Расширен встроенный `gearbox_oil` справочник с 48 до 99 записей.
- Добавлены отсутствующие семейства SEW-EURODRIVE: R87, R97, RF37, RF47, S47, SA37/47/57/67/77, K37/57/67, KA37, KF47, KH47, KH87/KH87B, KF37R17.
- Добавлены фактические исполнения Bonfiglioli: дополнительные C312/C412/C413/C512/C513/C612, A202/A412/A503, 301 L2, RAN38, MW110, W75, MVF30/44/49/86.
- Добавлены Brevini SL8504, Lenze GST05/GST07/GKS04/GKS06/GKS07, Rossi MRIV80, Tandler STD B1, ZIMM Z-50-SN.
- Для SEW R87/R97/RF37/RF47 добавлены ориентировочные OEM-объёмы по монтажным положениям из официального каталога SEW; варианты с двумя объёмами остаются вариантами и требуют выбора по исполнению/ступеням и проверки уровня.
- Для остальных новых записей без подтверждённой таблицы объёма используется `fillVerificationRequired=true`; объём масла не выдумывается и не переносится от похожей модели.

## Cross-OEM Guard

- Добавлен OEM/family resolver для SEW, Bonfiglioli, Brevini, Lenze, Rossi, Tandler, ZIMM, UNIT DRIVE и ABB.
- Если производитель/семейство распознаны, запись другого OEM больше не может стать даже `suggested`.
- Общий fuzzy matcher больше не применяется к редукторам без распознанного производителя/типоразмера. Строки вроде `Редуктор Линия №1` остаются `unmatched`.
- При конфликте данных (например, manufacturer=`BONFIGLIOLI`, а обозначение `MRV`, которое текущая методика относит к Rossi) автоматическое применение OEM-данных блокируется до инженерного подтверждения.
- ABB RV и неизвестные `HW A1` не получают выдуманный сервисный профиль.

## Миграция старых связей

При загрузке базы автоматически пересчитываются только автоматические привязки. Ложные связи `SEW -> UNIT DRIVE`, `Bonfiglioli -> UNIT DRIVE` и другие cross-OEM связи очищаются и заменяются корректными, если семейство уже есть в справочнике. Если остаётся OEM-конфликт, связь сбрасывается в `unmatched`.

Ручные `actualLibraryEntryId` не перезаписываются.

## Проверка рабочей базы

На последней производственной базе:

- компонентов редукторов/мотор-редукторов: 335;
- автоматически распознано безопасно: 305;
- cross-OEM совпадений после обновления: 0;
- намеренно не распознано: 30.

Оставшиеся 30 — это 19 OEM-конфликтов MRV (требуют проверки производителя), 4 ABB RV без подтверждённой сервисной методики, 3 `HW A1`, 3 общих строки `Редуктор Линия №1/№2` и 1 `Мотор-редуктор` без модели.
