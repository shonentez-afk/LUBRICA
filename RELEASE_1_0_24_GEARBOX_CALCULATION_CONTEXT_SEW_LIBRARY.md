# LUBRICA 1.0.24 — Gearbox calculation context & SEW K-series library

Исправлено отображение подшипникового расчёта в карточке редуктора. Для категории `gearbox_oil` теперь показывается только редукторный расчёт: рабочий объём/уровень, долив, замена масла и периодичность.

В Справочник добавлены SEW-EURODRIVE KA57B, KA77B, KA87B и KA107B с ориентировочными объёмами масла M1–M6. Эти типоразмеры обнаружены в текущей производственной базе. Значения справочные: приоритет имеют шильдик, конкретное исполнение, монтажное положение и фактический контроль уровня по OEM.

Старые точки редукторов со статусом `unmatched` теперь могут повторно сопоставиться со Справочником после расширения встроенной библиотеки.
