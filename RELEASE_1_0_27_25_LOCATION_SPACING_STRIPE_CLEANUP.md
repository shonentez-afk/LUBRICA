# LUBRICA 1.0.27.25 — Location spacing / stripe cleanup

Исправлен визуальный дефект карты смазки после 1.0.27.24.

- Колонка «Точка смазки» расширена с 180 до 210 px, чтобы содержимое «Линия / участок» не выглядело прижатым к ней.
- Для «Линия / участок» добавлен внутренний отступ слева и минимальная ширина 245 px.
- Удалён box-shadow/разделитель на правой границе sticky-колонки «Точка смазки», который визуально воспринимался как вертикальная полоса.
- «Линия / участок» остаётся обычной прокручиваемой колонкой и не получает sticky-позиционирование.
- Бизнес-логика, данные и расчёты не изменялись.
