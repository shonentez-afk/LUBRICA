# LUBRICA 1.0.33.44 — Unified Shaft Bearing Support Context

- Для валов и конвейеров убран вентиляторный контекст из обычных SKF SNL-опор.
- Единая модель опор вала: UC/UK корпусной узел; SKF SNL + внутренний подшипник; обслуживаемый подшипник без подтверждённого корпуса.
- SKF SNL, боковая подача: досмазывание + плановое обновление полного запаса (40%).
- SKF SNL, подача через канавку/отверстия: досмазывание + полное обновление по состоянию/при ТО; количество берётся из 20% OEM-заполнения корпуса, календарный интервал не выдумывается.
- При применении расчёта condition-based полная замена создаётся отдельным мероприятием «По состоянию / при ТО».
- UC/UK: штатное досмазывание; плановая полная разборка/замена всего заполнения автоматически не назначается без отдельного OEM-регламента.
