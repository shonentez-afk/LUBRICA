# LUBRICA 1.0.28.3 — Fan Classifier Filter UX

Исправление интерфейса классификатора после внедрения Fan Asset + Motor Structure UX.

## Исправлено

- В фильтр категорий классификатора возвращена отдельная категория `Вентилятор` (`fan`).
- Уже корректно классифицированные позиции вентиляторов с `maintenanceEquipmentType: fan` снова можно отфильтровать и проверить отдельно.
- Логика распознавания вентиляторов не изменялась: используются существующие результаты классификатора 2.3.
- Новая структура `позиция вентилятора -> Fan Asset + Motor Asset` сохранена.
- ПЧ не добавляется в Lubrication Domain и не участвует в Fan Bearing Arrangement Engine.

## Защита от регрессии

Версия меняет только UX-фильтр классификатора и номер приложения. Данные Fan Bearing Arrangement Engine и логика распознавания не меняются.
