# LUBRICA 1.0.29 — Lubrication Domain Cleanup Engine

## Цель
Отделить полную импортированную структуру предприятия от рабочего дерева карты смазок и убрать из очереди кандидатов заведомо несмазываемые статические элементы без физического удаления исходных данных.

## Реализовано
- `EXCLUDED_AUTO` для положительно распознанных статических/электрических объектов, не относящихся к карте смазок.
- `STRUCTURE_ONLY` для родителей, которые сами не обслуживаются, но нужны как навигационный контекст обслуживаемых потомков.
- `RELEVANT` для подтверждённых/ручных объектов и оборудования, уже имеющего точки/узлы обслуживания.
- `PENDING_REVIEW` для неопределённых объектов; они не удаляются и остаются доступны в кандидатах/полной структуре.
- Кнопка `Очистить рабочую структуру` в дереве.
- Переключатель `Полная структура` / `Рабочее дерево`.
- В кандидатах очередь по умолчанию показывает только реальные кандидаты, требующие проверки и распознанное оборудование; `Не классифицировано` вынесено в отдельную вкладку.
- Отдельная вкладка `Исключено` сохраняет полный аудит автоматически исключённых записей.

## Безопасность
- Импортированные equipment/components физически не удаляются.
- Точки смазки, мероприятия, расчёты и маршруты не удаляются.
- Наличие существующей точки/узла блокирует автоматическое исключение соответствующего оборудования.
- Неопределённый объект не исключается только из-за низкой уверенности классификатора.
