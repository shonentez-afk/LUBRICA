# LUBRICA 1.0.27 — Unified Simple Approval UX

Простой режим калькулятора переработан вокруг одного пользовательского сценария: рассчитать → проверить три результата → принять их.

- Добавлен блок «Быстрое утверждение» с дозой, первичным заполнением и периодичностью.
- Каждый доступный расчёт можно утвердить одной кнопкой «Принять».
- Кнопка «Принять все доступные» утверждает сразу все готовые числовые результаты.
- Источник утверждения формируется автоматически из источника расчётной методики; пользователю не требуется вручную копировать название OEM-документа.
- Недоступные результаты не могут быть утверждены случайно.
- Для ручной корректировки значения/источника остаётся экспертный режим.
- Быстрое утверждение использует существующую строгую модель provenance: рассчитанное и утверждённое значения остаются раздельными.
