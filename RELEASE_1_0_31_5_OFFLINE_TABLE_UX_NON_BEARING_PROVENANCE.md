# LUBRICA 1.0.31.5 — Offline Table UX & Non-Bearing Provenance

- Исправлено отдельное окно `#offlineEvidenceDialog`: модальное окно больше не прокручивается горизонтально целиком; горизонтальный скролл ограничен таблицей.
- Заголовок и кнопка закрытия остаются видимыми; нижняя кнопка закрытия находится в фиксированной области модального layout.
- Заголовки технических полей локальных datasets переведены в человекочитаемые русские подписи; исходный ключ доступен через title.
- Заголовок таблицы sticky, добавлена компактная сводка количества строк / типа evidence / offline status / даты проверки.
- Технические `sourceId/datasetId` убраны из основного потока в раскрываемый блок.
- Добавлен `calculations/non-bearing-provenance.js` как расширяемый resolver provenance для SEW-EURODRIVE, UNIT DRIVE, FRANCIA и цепей.
- Расчёт редуктора сохраняет `provenance` (`sourceId`, `datasetId`, `datasetVersion`, `evidenceType`) вместе с результатом, не меняя числовую математику.
- Product data цепей явно не владеют дозой/интервалом смазывания.
