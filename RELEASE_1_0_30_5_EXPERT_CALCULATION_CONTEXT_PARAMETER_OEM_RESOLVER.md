# LUBRICA 1.0.30.5 — Expert Calculation Context & Parameter OEM Resolver

## Что изменено

### REITZ + раздельные SNL-опоры
Для application-specific REITZ KXE расчёт теперь разделён по параметрам:
- досмазывание: количество и период — REITZ;
- первичное/новое заполнение: количество — REITZ;
- отдельный период полного обновления: если REITZ его не задаёт, SKF SNL предлагается только как явный fallback для периодичности.

Контрольный пример `SNL 522-619 + 22222K + 1450 об/мин + REITZ`:
- досмазывание: 100 г / 460 ч — REITZ;
- новое заполнение: 1100 г — REITZ;
- SKF fallback до подтверждения не применяется;
- после явного принятия SKF fallback период полного обновления: 2300 ч (5 фактических циклов досмазывания), при этом количество остаётся 1100 г REITZ.

### Lifecycle полной замены
Добавлены состояния:
- `CALCULATED`;
- `FALLBACK_AVAILABLE`;
- `PARTIAL_OEM`;
- `REVIEW_REQUIRED`;
- `CONDITION_BASED`;
- `NOT_APPLICABLE`.

Отсутствие отдельного REITZ-интервала больше не трактуется как `fullRenewal=false`.
Неполный цикл не создаёт фиктивное плановое мероприятие. Отдельное мероприятие «Полная замена смазки» создаётся только когда количество и период полностью определены/приняты.

### Экспертный UI
Основной поток перестроен на последовательные видимые шаги:
1. Конструкция и идентификация;
2. Применённые методики;
3. Исходные данные;
4. Результат обслуживания;
5. Проверка и применение.

Нумерация видимых шагов пересчитывается динамически, поэтому пропусков типа `01 → 03` больше нет.

Разделены:
- производитель вентилятора;
- производитель корпуса/блока;
- производитель внутреннего подшипника;
- источник метода для каждой операции/параметра.

Для двух раздельных SNL явно показывается, что расчёт относится к одной опоре. Для совмещённых блоков сохранена отдельная модель: одна точка подачи не приравнивается автоматически к одному подшипнику.

### Технические поля
P/C, ручные базы, Universal-параметры, ручные override и другие диагностические поля сохранены, но скрыты за отдельным переключателем «Показать технические параметры и ручные переопределения». OEM-таблицы SKF/REITZ остаются раскрывающимися, как и раньше.

## Что не менялось
- REITZ ZLG;
- NSK auto-OEM;
- SKF SNL standalone;
- VLU/INA-Schaeffler;
- Fan Bearing Arrangement Engine;
- существующие таблицы OEM.
