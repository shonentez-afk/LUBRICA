# LUBRICA 1.0.33.51 — Oscillating Constructor Single-Mode UX Hotfix

## Причина
В 1.0.33.48–1.0.33.50 в конструктор системы качания ошибочно были перенесены элементы расчётного UX: «Простой режим», «Экспертный режим» и верхняя кнопка «Обоснование». В архитектуре LUBRICA эти режимы относятся к расчёту смазки, а не к конструкторам оборудования.

## Исправлено
- удалён переключатель «Простой режим / Экспертный режим» из конструктора системы качания;
- удалена верхняя кнопка «Обоснование» из этого конструктора;
- удалены скрытые expert-only технические блоки и связанные CSS-правила;
- сохранены все рабочие поля конструктора: название, роль, сторона, место обслуживания, фактическая конструкция, найденный ТМЦ, маркировка/уточнение;
- сохранены transactional lifecycle, фактические guards, SNL/SNH/UC-UK delegation, cleanup и idempotency 1.0.33.49–1.0.33.50;
- режимы «Простой / Экспертный» в расчётных модулях не изменялись.

## Архитектурное правило
Конструкторы оборудования в LUBRICA однорежимные и описывают фактическую физическую конструкцию. «Простой / Экспертный» применяются только в расчёте смазки и связанных расчётных представлениях.
