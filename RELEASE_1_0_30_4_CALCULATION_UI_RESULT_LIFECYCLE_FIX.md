# LUBRICA 1.0.30.4 — Calculation UI Result & Lifecycle Fix

## Исправлено
- Простой режим теперь синхронизирует карточку «Результат расчёта» при каждом автоматическом пересчёте. Исправлен дефект 1.0.30.3, из-за которого REITZ мог быть рассчитан в экспертном режиме как 100 г / 460 ч, а простая карточка оставалась «Нет расчёта».
- В экспертном режиме разделены термины: «Производитель подшипника / вставки», «Производитель вентилятора», «Методика обслуживания SNL».
- Селектор ручного метода дозы больше не выглядит как текущая выбранная OEM-методика: «Авто — лучший доступный OEM → LUBRICA».
- Если политика требует плановой полной замены, но отдельного мероприятия ещё нет, простой режим показывает напоминание. После применения расчёта существующий lifecycle создаёт отдельное мероприятие «Полная замена смазки».
- Для REITZ KXE single, где fullRenewal=false, ложное напоминание не показывается.

## Не менялось
Формулы, OEM-таблицы, resolver и расчётные значения REITZ/SKF/NSK/ZLG не изменялись.
