# LUBRICA 1.0.33.70 RC — инженерные решения по ТМЦ (Stage 2)

**Предыдущая принятая база:** 1.0.33.69 RC / Stage 1. **Статус:** функциональный кандидат; не создавать ZIP и тег до окончательной проверки.

## Зачем

Продолжение Plant Lubrication Point Completion (Issue #12). Инженер должен разбирать реальные импортированные компоненты по машине, не создавать виртуальные опоры и не терять связь между исходной ТМЦ и созданным местом обслуживания.

## Реализовано

- Во вкладке `Контроль` можно раскрыть оборудование и последовательно рассмотреть конкретные ТМЦ (по 15 записей за страницу).
- Четыре решения: `Создать физическую точку`, `Конструктивный контекст`, `Не смазывается`, `Требует уточнения`.
- Причина решения обязательна; для создания физической точки и исключения из смазки обязателен источник проверки. Создание точки дополнительно требует явного подтверждения физического места.
- Предпросмотр / проверка решения — без записи в БД; сохранение — только после подтверждения пользователя.
- Создание физической точки использует **уже существующий** `LubricaCandidateFinalizer` с корректными категориями и мероприятиями `review`, а не второй конструктор. Положение каждой точки задаёт инженер.
- Данные provenance на исходной ТМЦ (engineeringDecision / engineeringDecisionHistory) и на созданной точке (engineeringSources.physical).
- Повторное применение одного решения безопасно (no-op), повторная точка для того же физического source component не создаётся.
- Безопасная отмена классификационного решения; для созданной точки — только до изменения параметров, утверждения мероприятия и появления маршрутов/выполнений, удаляются только собственные node/point/task.
- Решения сохраняются при повторной классификации и импорте; изменение имени/оборудования/категории исходной ТМЦ даёт QA-предупреждение и не скрывается.
- Для схемы вентилятора, вращающегося узла, механизма качания используется специализированный конструктор. Общий мастер не обходит его.
- Исходные user JSON, утверждённые мероприятия, история и маршруты не изменяются автоматически.
