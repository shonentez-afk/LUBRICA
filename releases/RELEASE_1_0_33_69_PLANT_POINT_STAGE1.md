# Release 1.0.33.69 RC — Plant Point Safety & Candidate Review Queue (Stage 1)

**Production predecessor:** 1.0.33.68. **Scope:** первая итерация системного завершения карты смазки предприятия. Это не финал плана.

## Что добавлено

1. В существующий `Контроль` добавлены проверки условно обслуживаемых SKF sealed spherical roller, включая `BS2-2208-2CS/VT143`.
   - Закрытый SKF 2CS **не** означает автоматический запрет досмазывания; действуют grease-life и OEM-условия.
   - Для необходимости повторной смазки показывается контрольный SKF `Gp=0.0015×D×B`, но он не заменяет инженерную проверку оборудования.
   - Универсальные расчёты открытых подшипников не выдаются за подтверждённый OEM для sealed bearing.
   - Мероприятие полной замены смазки закрытого подшипника получает требование подтвердить OEM-процедуру.
   - Данные и существующие мероприятия **не переписываются автоматически**.
2. Контроль материалов: плотность вне правдоподобного диапазона, конфликт ISO VG и вязкости при 40 °C для масел.
3. Read-only очередь реальных ТМЦ-кандидатов по оборудованию, с фильтром линии, подсчётом уже связанных компонентов, приоритетом по категориям, открытием конкретного оборудования.
4. Целевой регрессионный тест и включение в `test/run_all.sh`.

## Базовые факты

В предоставленной базе 2026-11-05: 1188 equipment, 5659 components, 501 points, 517 tasks. 468 tasks имеют статус review; 45 approved; 4 disabled. 1443 component candidate/review по контролируемым смазочным категориям (в том числе 105 coupling) не являются 1443 готовыми смазочными точками.

На текущей базе нет сохранённых маршрутов/фактических запусков/плановых строк. Они должны возникать после инженерного подтверждения мероприятий, а не создаваться автоматически из `review`.
