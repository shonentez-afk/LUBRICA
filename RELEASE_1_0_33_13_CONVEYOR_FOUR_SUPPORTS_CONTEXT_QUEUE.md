# LUBRICA 1.0.33.13 — Conveyor 4-support physical arrangement + candidate queue context

## Исправлено
- Для ленточного конвейера с фактически импортированными приводным и натяжным/ведомым валами конструктор формирует физическую схему 2 вала x 2 опоры = 4 подшипниковые точки.
- Импортированная позиция подшипника используется как исходное обозначение для четырёх физических мест только в подтверждённой пользователем схеме; каждую точку можно уточнить отдельно до утверждения расчёта.
- Рабочая цепь остаётся отдельной точкой.
- Мотор-редуктор показывается и создаётся как отдельный приводной сервисный узел, а не теряется за пределами конструктора.
- Дочерние ТМЦ распознанного ленточного конвейера больше не дублируются в общей очереди кандидатов: они обрабатываются в Conveyor Arrangement.
- Валы после подтверждения схемы фиксируются как конструктивный контекст без самостоятельной точки смазки.
- Classification version: 2.5.
