# LUBRICA 1.0.31.9 — Source Registry Modal UX Fix

- Унифицировано окно «Источники» для всех калькуляторов.
- Inline Source Registry теперь позиционируется относительно viewport, а не размеров родительского калькулятора.
- Убрана горизонтальная прокрутка всего окна; длинный текст переносится внутри карточек.
- Шапка, поиск/фильтр, примечание и нижняя кнопка остаются доступными; вертикально прокручивается только список источников.
- Исправлена работа в узких окнах и на небольших экранах.
- Расчётные формулы и OEM-данные не изменялись.
