# LUBRICA 1.0.33.29 — Gearbox Mounting Position Resolver + UX parity

- Карточка редуктора приведена к общему расчётному shell: в простом режиме показывается только компактный итог из трёх карточек; идентификация и исходные параметры перенесены в экспертный режим.
- Добавлен отсутствовавший CSS для `cols-3`, поэтому рабочий объём / замена масла / долив больше не растягиваются тремя вертикальными блоками.
- При смене монтажного положения каталог редуктора пересчитывается заново, старый автоматически подставленный или утверждённый объём не переносится на новую позицию.
- Для OEM-позиций с одним объёмом значение подставляется сразу.
- Для SEW-позиций, где OEM-таблица содержит два допустимых объёма, показывается явный выбор варианта. LUBRICA не угадывает исполнение; после выбора одного из OEM-объёмов результат становится определённым.
- Для R67: M3=2.8 л, M4=3.2 л, M5=1.8 л, M6=2.0 л подставляются автоматически; M1 и M2 требуют выбора из OEM-вариантов, поскольку в локальном OEM-наборе сохранены по два значения.
- Синхронизация рассчитанного объёма и периода с мероприятиями сохранена.
