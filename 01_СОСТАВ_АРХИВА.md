# LUBRICA 1.0.33.67 — карта production-поставки

Исходная production-поставка соответствует принятому baseline **1.0.33.67**. После переноса в GitHub проект дополнительно содержит управляющую документацию в `project/` и GitHub workflows в `.github/`; они не входят в исходный runtime-архив, но являются обязательной частью текущей проектной памяти.

Этот документ является картой **исходной production-поставки**. Для полного текущего состава GitHub дополнительно использовать `project/PROJECT_INDEX_RU.md`, `project/MANIFEST_POLICY_RU.md` и `project/CURRENT_FILE_MANIFEST_SHA256.txt`. Исторические Stage/RC/approval-отчёты могут оставаться как доказательная история, но не определяют runtime.

## Запуск

1. Полностью распаковать архив, не меняя структуру папок.
2. Открыть `index.html` в Microsoft Edge через `file://`.
3. При необходимости один раз запустить `Создать ярлык LUBRICA.bat` — на рабочем столе появится ярлык LUBRICA с фирменной иконкой.
4. Рабочие данные хранятся в отдельном JSON. Перед обновлением версии сохранять JSON и backup.

## Папки

- `./` — Корень поставки: точка входа, метаданные, создание Windows-ярлыка и два постоянных технических документа.
- `assets` — Общие статические ресурсы интерфейса.
- `assets/guide` — Актуальные скриншоты интерфейса LUBRICA 1.0.4, встроенные во внутреннее руководство пользователя.
- `assets/icons` — Фирменные изображения LUBRICA: логотип шапки, favicon, квадратные иконки и Windows ICO.
- `assets/oem/izoteh` — Локальная OEM-документация Izoteh PP-53736: руководство и листы сборочного чертежа 53736.
- `bearings` — Библиотека подшипников, справочные данные, UI и специализированный расчёт.
- `calculations` — Расчётный framework, реестр, адаптеры и инженерные калькуляторы разных типов компонентов.
- `checklist` — Фактическое выполнение маршрута, рабочий чек-лист и ФРВ.
- `components` — Общая библиотека компонентов, классификационные схемы, matching и binding.
- `core` — Ядро приложения: схема БД, миграции, безопасность, state, storage, Recovery и диагностика.
- `data` — Демонстрационные данные и версия приложения.
- `export` — Экспорт, финальный Excel-шаблон и интерфейс экспорта.
- `import` — Импорт XLSX/CSV, классификация кандидатов и результаты импорта.
- `js` — Финальная runtime-инициализация приложения.
- `lubrication` — Редактор мероприятий физической точки.
- `materials` — Библиотека материалов/инструментов, маркировка и печать этикеток.
- `qa` — Read-only инженерный «Контроль» готовности программы смазки.
- `routes` — Маршруты, подготовка, планирование, План/факт, аналитика и дашборд.
- `structure` — Иерархия предприятия, дерево, правая панель, диалоги и мастер физических точек.
- `test` — Автоматизированные unit, integration, UX/UI и regression тесты; run_all.sh — официальный агрегатор.
- `ui` — Общие пользовательские представления: карта, настройки, руководство, навигация и вспомогательные инструменты.
- `vendor` — Локальные сторонние библиотеки, необходимые для работы без сети.
