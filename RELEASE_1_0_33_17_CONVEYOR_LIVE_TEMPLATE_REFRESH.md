# LUBRICA 1.0.33.17 — Conveyor Live Template Refresh

Исправлен рассинхрон конструктора ленточного конвейера для ранее классифицированных записей.

- При каждом открытии конструктора evidence и supportLayout пересобираются из текущей структуры/ТМЦ.
- Старый сохранённый maintenanceTemplate больше не определяет UI конструктора.
- Все конвейеры с приводным и натяжным/ведомым валом получают единый экран 2 вала × 2 опоры.
- Несколько найденных подшипников назначаются инженером на четыре физические опоры.
- Одно обозначение предлагается на четыре места только как проверяемая подсказка.
- Ручной ввод продолжает использовать тот же supportLayout.
