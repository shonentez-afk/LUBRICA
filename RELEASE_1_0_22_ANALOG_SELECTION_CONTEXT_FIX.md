# LUBRICA 1.0.22 — Analog selection context fix

## Исправлено

Кнопка **«Заполнить по аналогу»** в Карте смазки могла показывать предупреждение
«Сначала выберите мероприятие точки», даже когда мероприятие и физическая точка уже были открыты справа.

Причина: модуль аналогов пытался читать `window.selectedId`, а выбранное мероприятие хранится
в общем lexical state рабочего пространства и не является свойством `window`.

## Новая логика

- обработчик кнопки передаёт текущий `taskId` в модуль аналогов явно;
- модуль сначала разрешает физическую точку по переданному `taskId`;
- дополнительно кнопка хранит `pointId` текущей открытой точки как резервный контекст;
- если контекст действительно отсутствует, выводится корректное сообщение о невозможности определить точку;
- поиск аналогов, перенос профиля, массовое применение и защита от перезаписи не изменены.

## Проверено на пользовательском сценарии

`LP-000008` — правая опора `UCFC 208`, мероприятия `TASK-000013/14`.
Аналог `LP-000007` — левая опора `UCFC 208`, уже заполненная материалом, инструментом,
расчётными количествами и календарной периодичностью.

После исправления нажатие «Заполнить по аналогу» из `TASK-000013` корректно открывает
диалог для `LP-000008` и рекомендует `LP-000007` как лучший источник.
