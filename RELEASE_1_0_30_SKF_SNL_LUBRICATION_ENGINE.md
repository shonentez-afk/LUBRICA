# LUBRICA 1.0.30 — SKF SNL Lubrication Engine

Дата: 2026-09-09

## Цель

Добавлен отдельный расчётный контур SKF SNL для раздельных подшипниковых корпусов. SNL больше не рассчитывается как обычный одиночный подшипник без учёта корпуса и способа подачи смазки.

## Простой режим

Для точки SNL пользователь выбирает только фактический способ подачи смазки:

- **Сбоку подшипника** — SKF `Gp = 0,005 × D × B`.
- **Через канавку / отверстия наружного кольца** — SKF `Gp = 0,002 × D × B`.

Маркировка корпуса и внутренний подшипник подтягиваются из Fan Bearing Arrangement Engine, если они уже подтверждены. Повторно вводить их не требуется.

## Плановая полная замена / обновление

Для подачи сбоку используется отдельный рабочий цикл полного обновления запаса смазки корпуса. Количество берётся из встроенной таблицы SKF SNL для 40% рабочего заполнения корпуса. По руководству SKF полное обновление требуется ориентировочно после пяти пополнений; если рассчитанный интервал досмазывания уже составляет 6 месяцев или больше, обновление планируется на соответствующем сервисном интервале.

Для подачи через канавку/отверстия используется меньшая дозировка и ориентир 20% заполнения корпуса; плановая полная замена автоматически не создаётся, так как SKF указывает, что для этой схемы она обычно требуется только в исключительных случаях.

## Два мероприятия одной точки

Если у точки уже есть мероприятие **«Досмазывание»**, оно не заменяется. При необходимости LUBRICA создаёт второе отдельное мероприятие **«Полная замена смазки»** для той же точки:

- собственная доза;
- собственная периодичность;
- собственное утверждение;
- общий источник расчёта SKF SNL.

При последующей смене способа подачи на канавку/отверстия ранее созданное расчётное мероприятие полной замены не удаляется из истории, а переводится в состояние проверки/неактуальности и исключается из утверждённого планирования.

## Экспертный режим

Сохранены все инженерные параметры и источники:

- точная маркировка SNL;
- внутренний подшипник и D/B;
- выбранный способ подачи;
- формула дозы;
- 20% / 40% справочная заправка корпуса;
- расчёт интервала;
- политика полного обновления;
- источник SKF.

## OEM-приоритет

SKF SNL Engine является OEM-контекстом корпуса. Если для конкретного вентилятора существует более конкретная OEM-методика производителя машины, она должна иметь более высокий приоритет. Автоматическое сопоставление иной OEM-таблицы с SNL по похожему обозначению не выполняется без подтверждения применимости.

## Совместимость

Изменение не затрагивает ZLG, UC/UK/UEL, опорно-поворотные подшипники и обычные одиночные подшипники. Существующие мероприятия и история не удаляются.
