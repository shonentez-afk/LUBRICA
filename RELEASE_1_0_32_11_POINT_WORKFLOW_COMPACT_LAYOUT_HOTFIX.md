# LUBRICA 1.0.32.11 — Point Workflow Compact Layout Hotfix

Исправлена компоновка блока «Рабочее состояние» в узкой правой карточке точки.

- Статус, пояснение и кнопка утверждения теперь расположены вертикально.
- Select занимает доступную ширину карточки.
- Пояснение больше не сжимается до узкой колонки и нормально переносится строками.
- Кнопка «Утвердить мероприятие» занимает всю ширину блока и допускает перенос текста.
- Бизнес-логика approvalStatus и расчётное ядро не изменялись.
