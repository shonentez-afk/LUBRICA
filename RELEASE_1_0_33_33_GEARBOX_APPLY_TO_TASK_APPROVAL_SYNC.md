# LUBRICA 1.0.33.33 — Gearbox Apply-to-Task Approval Sync

Исправлена ошибка, при которой после нажатия «Применить расчёт» рабочий объём редуктора оставался только расчётным значением (`quantity.calculated`) и не попадал в утверждённое поле мероприятия (`quantity.approved`).

Изменения:
- `calculations/gearbox-oil-adapter.js`: явное действие «Применить расчёт» теперь фиксирует текущий `effectiveFillLiters` как применённый/утверждённый рабочий объём (`approvedFillLiters`, `appliedFillLiters`, `appliedAt`) и сразу записывает его в мероприятие «Замена масла».
- `lubrication/task-editor.js`: карточка мероприятия сохраняет применённый объём и не сбрасывает его обратно в пустое поле.
- `core/database-normalizer.js`: базы, созданные в 1.0.33.25–1.0.33.32, автоматически ремонтируются. Для старого расчёта редуктора, который уже был сохранён через «Применить расчёт», `effectiveFillLiters` переносится в `approvedFillLiters` и в количество мероприятия.
- `ui/workspace.js` менять не потребовалось: пометка `расч.` уже является fallback только когда утверждённое количество пустое. После исправленной синхронизации в карте отображается обычное `2.8 л` без `расч.`.

Жизненный цикл остаётся прежним: расчёт применяет рабочие значения к мероприятию, но статус мероприятия может оставаться «Требует проверки» до отдельного инженерного подтверждения/включения в план.
