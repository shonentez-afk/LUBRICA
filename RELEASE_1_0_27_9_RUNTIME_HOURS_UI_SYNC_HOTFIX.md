# LUBRICA 1.0.27.9 — Runtime Hours UI / Schedule Sync Hotfix

Исправлен дефект карточки мероприятия, при котором периодичность по наработке могла отображаться как `2250 ч` внутри поля значения, после чего при сохранении добавлялся второй суффикс `ч`. Также в сохранённых задачах могли одновременно оставаться `runtimeHours` и старые `calendarUnit=weeks`.

Изменения:
- значение периодичности по наработке теперь загружается прежде всего из `schedule.runtimeHours`, а не разбирается из `legacyText`;
- в поле значения показывается только число (`2250`), единица отдельно — `часы работы`;
- при сохранении любой случайный текст `2250 ч`, `2250 ч ч` нормализуется в `runtimeHours: 2250` и `legacyText: "2250 ч"`;
- при стратегии `По наработке` календарные поля `calendarValue/calendarUnit` очищаются, добавлен `runtimeUnit: "hours"`;
- в статическом списке единиц добавлена опция `часы работы`, чтобы UI не оставался с пустым select до динамического обновления;
- аналогичная нормализация добавлена в редактор мероприятий структуры.
