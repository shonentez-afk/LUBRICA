# LUBRICA 1.0.33.52 — SKF BS2-2208-2CS/VT143 Bearing Library Hotfix

Добавлена OEM-точная запись SKF `BS2-2208-2CS/VT143` во встроенную библиотеку подшипников.

Параметры: d=40 мм, D=80 мм, B=28 мм, масса 0,57 кг, тип — сферический роликоподшипник, двухстороннее контактное уплотнение 2CS (NBR), заводская смазка SKF LGEP 2 по суффиксу VT143.

Parser Bearing Library теперь распознаёт семейство BS2 с суффиксом `2CS/VT143`, сохраняет `VT143`, определяет 2CS как sealed и передаёт точное OEM-обозначение в созданную точку без повторного добавления суффикса.

Расчётный модуль дополнительно распознаёт 2CS/2CS2/2CS5 как закрытые исполнения и показывает существующее предупреждение о необходимости OEM-подтверждения досмазывания. Формула расчёта не изменена.
