# LUBRICA 1.0.6 - hotfix окна «Инженерное подтверждение»

Исправлена регрессия компоновки окна подтверждения кандидата.

Что было:
- появлялся горизонтальный скролл;
- поле «Положение» и часть мероприятий уходили вправо;
- длинные названия мероприятий обрезались;
- на узком окне форма сохраняла десктопную четырёхколоночную раскладку.

Что изменено:
- окно ограничено рабочей шириной до 980 px и шириной viewport;
- горизонтальная прокрутка запрещена;
- добавлена адаптация по фактической ширине самого диалога через container queries;
- при ширине < 850 px форма перестраивается в две колонки;
- при ширине < 560 px - в одну колонку;
- поле «Положение» на компактной ширине занимает отдельную строку;
- чипы мероприятий переносят длинный текст;
- нижние кнопки на узких экранах становятся вертикальными.

Логика создания точек/мероприятий не менялась.
