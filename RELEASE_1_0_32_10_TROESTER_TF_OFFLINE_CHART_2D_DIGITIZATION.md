# LUBRICA 1.0.32.10 — Tröster tf Offline Chart + 2D Digitization

- Добавлена локальная копия OEM PDF Tröster и читаемая диаграмма стр. 7.
- В окне локальных данных показана диаграмма с русской легендой и правилами чтения.
- В калькуляторе Tröster появилась кнопка «Открыть диаграмму Tröster».
- Автоматический tf восстановлен не через n·d-формулу, а через калиброванную 2D-оцифровку исходного графика: шкала I/II/III + d + n.
- Автоматизированный диапазон d: 40–200 мм; вне него требуется ручная проверка графика.
- Оцифрованный результат имеет явный допуск ±15%.
- Ventapp machine-specific interval сохраняет высший приоритет.
- Температурная и позиционная поправки Tröster не изменены.
