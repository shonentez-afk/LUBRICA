# LUBRICA 1.0.27.4 — Auto Default, RPM & Stale Recalculation

## Исправлено
- Производитель больше не выбирается автоматически из справочной каталожной записи. Новый/старый расчёт без явного пользовательского выбора открывается в режиме «Авто / не указан».
- После первого сохранения выбор производителя считается явным и сохраняется.
- Рабочие обороты вынесены в верхний блок «Условия эксплуатации» и помечены обязательными для расчёта периодичности.
- Обороты, температура, положение вала, нагрузка, загрязнение и вибрация находятся в одном видимом рабочем блоке и пересчитывают оба цикла в реальном времени.
- Если обороты не указаны, интерфейс прямо сообщает, что доза может быть рассчитана, а периодичность — нет.
- Для ранее утверждённых расчётов предыдущих версий добавлен баннер «Ранее утверждённые значения требуют проверки» и кнопка «Пересчитать и заменить старые значения». Старые утверждения не заменяются автоматически без подтверждения пользователя.
- При замене старых значений обновляются оба рабочих цикла: досмазывание и полная замена смазки, вместе с их источниками.

## Совместимость
Старые данные не удаляются. Пересчёт выполняется только после явного подтверждения пользователя.
