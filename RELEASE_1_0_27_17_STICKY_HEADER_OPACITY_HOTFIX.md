# LUBRICA 1.0.27.17 — Sticky Header Opacity Hotfix

Исправлена прозрачность первых закреплённых заголовков в Карте смазки.

Причина: после перехода первых трёх колонок в sticky-блок браузер при совместной вертикальной и горизонтальной прокрутке мог композитить содержимое строк поверх/сквозь первые `th`, несмотря на фон `thead`.

Изменения:
- у `thead` и всех его `th` принудительно задан непрозрачный фон шапки;
- для первых трёх sticky-заголовков явно заданы `top`, `left` и повышенный `z-index`;
- добавлен изолированный слой `isolation:isolate`;
- добавлен собственный непрозрачный фон-подложка через `::before`, чтобы содержимое строк не просвечивало даже при особенностях compositor Edge/Chromium;
- sticky-колонки строк, ширины и бизнес-логика не менялись.

Изменение только UI/CSS.
