# LUBRICA 1.0.33.46 — Conveyor Field Layout Hotfix

## Исправлено
В конструкторе ленточного конвейера поле «Точка обслуживания» отображалось в устаревшей колонке шириной 80 px, хотя переключатель «Включить точку» уже был вынесен отдельной строкой. Из-за этого «Узел / ТМЦ» визуально накладывался на название точки.

## Новая компоновка
- «Включить точку» — отдельная строка.
- «Точка обслуживания» — самостоятельная широкая колонка.
- «Узел / ТМЦ» — самостоятельная колонка без наложений.
- «Категория» и «Положение» — отдельные колонки.
- При средней ширине — сетка 2×2.
- При узкой ширине — поля последовательно переходят в одну колонку.

Логика создания/исключения точек, назначение ТМЦ и мероприятий не менялись.
