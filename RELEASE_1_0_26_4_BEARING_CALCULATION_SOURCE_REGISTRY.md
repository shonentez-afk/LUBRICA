# LUBRICA 1.0.26.4 — Bearing Calculation Source Registry

Добавлен встроенный реестр источников расчёта подшипников.

## Что добавлено
- Кнопка **«Источники расчёта»** в справочнике подшипников.
- Кнопка **«Источники»** прямо в калькуляторе подшипника.
- Поиск и фильтрация по SKF / NSK / FAG-Schaeffler / NTN-SNR / Timken / инженерным методам.
- Для каждого источника: OEM, документ, редакция/тип документа, раздел, операции, формула/данные, область применимости, внутренние method-id LUBRICA, уровень доказательности, ссылка и дата проверки.
- Прямые ссылки на официальные документы/OEM-калькулятор.
- SKF sourceRef дополнен официальной ссылкой на Grease relubrication procedures.
- Timken sourceRef обновлён на проверенный Help Guide URL.

## Правило прослеживаемости
Реестр отделяет **источник расчётной методики** от **источника утверждённого пользователем значения**. Эти поля не взаимозаменяемы.
