# LUBRICA 1.0.21 — Заполнение точки по аналогу

Добавлена функция **«Заполнить по аналогу»** для подшипниковых точек.

## Назначение

Если в базе уже полностью заполнена точка с тем же точным обозначением подшипника, пользователь может перенести инженерный профиль вместо повторного ручного ввода.

## Что считается аналогом

Автоматически предлагаются только точки с тем же точным элементом Справочника либо с тем же нормализованным обозначением подшипника. Привязка к оборудованию не участвует в совпадении.

## Режимы

1. **Всё из аналога** — технический профиль/расчёт, TARGET/AS IS/OEM материал, мероприятия, инструмент, количества, периодичность и источники.
2. **Только материал и инструмент** — без изменения нормы, расчёта и периодичности.
3. **Выбрать данные** — пользователь выбирает отдельные группы полей.

## Защита данных

Никогда не копируются:
- id физической точки;
- equipmentId / nodeId;
- положение и местоположение;
- candidateOriginKey и связи кандидатов;
- утверждённый статус.

После переноса принимающая точка и затронутые мероприятия получают статус **«Требует проверки»**. Утверждение должно выполняться инженером заново.

## Мероприятия

Мероприятия сопоставляются по `activityType`, а при его отсутствии — по названию операции. Отсутствующие мероприятия могут быть созданы автоматически с новым `TASK-*` ID. Лишние мероприятия принимающей точки автоматически не удаляются.

## Массовое применение

Можно применить выбранный профиль ко всем другим незаполненным точкам с тем же подшипником. Точки, которые уже имеют полный материал + количество + периодичность, массово не перезаписываются.

## Аудит

На точке сохраняется `analogTransfer`, а на мероприятии — `analogSourcePointId` и `analogTransferredAt`, чтобы было видно, откуда были перенесены данные.
