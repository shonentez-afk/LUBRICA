# LUBRICA 1.0.33.64 — Izoteh PP-53736 Manual Add Parity

## Цель
Обеспечить полную работу специализированного конструктора гофрировщика-подпрессовщика Izoteh PP-53736 не только после импорта, но и при ручном создании оборудования.

## Исправлено
- В ручном диалоге оборудования добавлен профиль `Izoteh PP-53736 · гофрировщик-подпрессовщик`.
- Для выбранного профиля не требуется выдумывать внешний код позиции.
- При ручном создании автоматически формируется документированная структура: механизмы очистки, верхний/нижний роликовые транспортеры и подъёмный механизм.
- По OEM-документации создаются 8 физических цепей 12-B2 и 4 физических винта подъёмника.
- Создаются документированные K37, два KF37R17, Tandler A1 и две открытые пары зубчатое колесо/рейка.
- Подшипники без фактического обозначения не создаются.
- R77 создаются только после подтверждения фактического количества инженером; каждый подтверждённый привод получает отдельный физический component.
- S37 создаётся только после выбора `Установлен`.
- Повторное открытие/сохранение идемпотентно: точки, мероприятия и components не дублируются.
- Распознавание ручного оборудования расширено на обозначения `PP-53736` / `PP-53736-YU1`, а не только русское название.
- Применение конфигурации к аналогу на другой линии сохранено.

## Safety rules
Фактические ТМЦ имеют приоритет. Документированные физические элементы машины могут быть созданы из OEM-профиля; неподтверждённые подшипники и иные обслуживаемые пары не изобретаются.
