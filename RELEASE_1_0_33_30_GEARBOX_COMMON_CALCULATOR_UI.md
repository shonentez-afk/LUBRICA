# LUBRICA 1.0.33.30 — Gearbox Common Calculator UI

Исправлена UX-регрессия расчётного модуля редуктора после 1.0.33.29.

## Что изменено

- Редуктор переведён на тот же визуальный каркас, что и остальные актуальные расчётные модули LUBRICA:
  - общий заголовок «РАСЧЁТ СМАЗКИ»;
  - «Простой режим / Экспертный режим / Обоснование»;
  - `calc-simple-overview`;
  - единый главный блок «Рекомендация»;
  - единая контекстная полоса;
  - единый блок «Результат обслуживания» на `simple-approval-card`.
- Простой режим больше не является только витриной результата. В нём доступны минимально необходимые рабочие данные:
  - распознанный редуктор;
  - монтажное положение;
  - способ контроля уровня;
  - выбор одного из нескольких OEM-объёмов, если таблица неоднозначна.
- Простой режим показывает рабочий объём, период замены и правило долива и позволяет сразу нажать «Применить расчёт».
- Производитель, полная модель, способ смазывания, ручное переопределение объёма, источники интервала и эксплуатационные параметры оставлены в экспертном режиме.
- При смене монтажного положения старый утверждённый объём по-прежнему инвалидируется и выполняется повторный OEM-resolve.
- Неоднозначные OEM-объёмы больше не скрыты в экспертном режиме: пользователь видит выбор именно там, где он нужен для завершения обычного рабочего сценария.
- Версия расчётного контура редуктора: 8.7; версия приложения: 1.0.33.30.

## Не менялось

- OEM-таблицы и правила выбора объёма;
- формулы и интервалы;
- приоритет OEM/шильдик/фактический уровень;
- синхронизация результата с мероприятиями;
- защита от автоматического выбора неоднозначного OEM-объёма.
