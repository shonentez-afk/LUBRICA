# LUBRICA 1.0.11 — Structure deletion lifecycle hotfix

## Исправлено

### 1. Пустая физическая точка после удаления последнего мероприятия

Ранее Карта смазки удаляла только task, поэтому после удаления всех мероприятий `lubricationPoint` оставался в базе и продолжал отображаться в Структуре.

Теперь при удалении последнего мероприятия система явно предупреждает, что это последнее мероприятие точки, и удаляет одновременно:
- мероприятие;
- ставшую пустой физическую точку.

Если у точки остаются другие мероприятия, удаляется только выбранное мероприятие.

### 2. Удаление элементов из Структуры

В правой карточке выбранного элемента добавлена кнопка `Удалить`.

Удаление безопасное, без скрытого разрушительного каскада:
- точку нельзя удалить, пока в ней есть мероприятия;
- узел нельзя удалить, пока в нём есть точки или дочерние узлы;
- оборудование нельзя удалить, пока есть дочернее оборудование, узлы, точки или импортированные компоненты;
- участок нельзя удалить, пока есть оборудование;
- линию нельзя удалить, пока есть участки/оборудование;
- завод нельзя удалить, пока есть линии;
- мероприятие нельзя удалить, если оно связано с текущим маршрутом, ревизией маршрута или историей выполнения.

Сначала пользователь должен удалить/отвязать дочерние данные. Это защищает историю маршрутов и выполнений.
