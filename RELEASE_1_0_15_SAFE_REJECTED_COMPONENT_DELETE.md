# LUBRICA 1.0.15 — Safe delete of rejected imported components

Исправлена блокировка удаления импортированного оборудования из Структуры.

Раньше любое наличие записи в `components[]` с `equipmentId` выбранного оборудования полностью запрещало удаление, даже если компонент уже был отклонён и не участвовал в программе смазки.

Новая логика:
- обычные дочерние объекты, узлы и точки по-прежнему блокируют удаление;
- рабочие, candidate/equipment/confirmed или связанные с точками компоненты по-прежнему блокируют удаление;
- только импортированные компоненты со статусом `rejected` или `excluded`, не связанные ни с одной точкой, считаются безопасно удаляемыми вместе с оборудованием;
- перед каскадом показывается явное подтверждение с количеством таких компонентов.

Проверено на пользовательской базе:
- `EQ-000032 Группа электрошкафов` → `COMP-0000126 Устройство тревоги...`, rejected;
- `EQ-000063 Группа электрошкафов` → `COMP-0000242 Устройство тревоги...`, rejected;
- у обоих объектов нет узлов и точек смазки, поэтому удаление разрешается безопасным каскадом.
