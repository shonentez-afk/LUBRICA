# LUBRICA 1.0.32.14 — Operating Condition Recalculation Hotfix

Исправлен UX/runtime-путь пересчёта условий эксплуатации в калькуляторе подшипников.

- Нагрузка, загрязнение, вибрация, положение вала, температура и обороты теперь вызывают немедленный пересчёт текущего результата.
- Для LUBRICA Universal 3.2 подтверждена работа коэффициентов: загрязнение, нагрузка и вибрация меняют рабочий интервал.
- Сохранённое утверждение не подменяет новый расчёт: при расхождении оно помечается как устаревшее и пользователь должен принять новый цикл.
- OEM-методики, которые не используют конкретный параметр, по-прежнему не получают выдуманных поправок.
- Расчётная архитектура CalculationContext → MethodResolver → CalculationPackage → MaintenancePolicy → UI Presenter не менялась.

Контрольный пример UCP 212, 300 об/мин, LUBRICA Universal 3.2: база 2250 ч; heavy contamination → 1125 ч; heavy load → 1575 ч; high vibration → 1350 ч; совместно → 473 ч.
