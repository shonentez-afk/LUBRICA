# LUBRICA 1.0.27.19 — FRANCIA Screw Jack Recognition & Lubrication

## Что исправлено
- Добавлено распознавание винтовых домкратов FRANCIA серий M35/M42/M55/M75 в исполнениях VT/VR даже по одному каталожному обозначению без слов «винтовой домкрат».
- Для `M42VR-TP-N-700-T-B-P2-1` распознаются: FRANCIA, M42VR, вращающийся винт VR, Tr30x6, ход 700 мм, редуктор N 1/24.
- Добавлены OEM-данные корпуса M35/M42/M55/M75: 50 / 150 / 400 / 750 см³ минеральной смазки NLGI 00.
- Для M42VR редукторная полость и винтовая пара разделены как разные зоны обслуживания.
- Добавлен специализированный расчёт винтовой пары: OEM-процедура + условия эксплуатации + циклы + калиброванный фактический расход.
- Не вводится выдуманная фиксированная OEM-доза для винта: FRANCIA требует периодически поддерживать чистую плёнку смазки, а частоту определять по среде, времени работы, скорости и циклам.
- Инженерный fallback по циклам явно маркируется как LUBRICA, класс D, и требует подтверждения.
- Синхронизация расчёта винта с мероприятием сохраняет рассчитанные/утверждённые циклы и, если калибрована, массу смазки.
